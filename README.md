# ميزان — مساحة تسوية الموردين

إصدار 0.3 — نسخة تجريبية عربية لمقارنة كشف المورد ودفتر AP داخل المتصفح. استيراد XLSX/CSV وPDF نصي بحدود أعمدة ومراجعة إلزامية، تأكيد المعنى والنطاق، مطابقة محافظة، مراجعة يدوية، وجسر حسابي اختياري وتصدير Excel. راجع [طريقة PDF وحدوده وأدلة الاختبار](docs/PDF.ar.md).

جولة الضغط السابقة: 79 اختبارًا ناجحًا وفحص مستقل لـ18 ملف Excel؛ تفاصيل العيوب المصححة وحدود الإثبات في [تقرير الضغط](audit/stress/REPORT.ar.md).

**نسخة تجريبية لم تثبت دقتها على عينات ميدانية مستقلة.** لا ندّعي صحة 100% ولا اعتمادًا محاسبيًا. راجع [الخطة](docs/TECHNICAL_PLAN.ar.md) و[التحقق والحدود](docs/VALIDATION.ar.md) قبل استخدام بيانات حقيقية. المستودع المعتمد: [mjodshamrani-ux/accounting](https://github.com/mjodshamrani-ux/accounting). حالة النشر والاختبارات تظهر في تبويب Actions.

## تشغيل محلي

Node 24 وpnpm 11.19.0:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## التحقق والبناء

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:browser
```

آخر أمر يحتاج بيئة تسمح بتشغيل Chromium. حزمة الاختبار تستخدم بيانات اصطناعية وتخدم `dist` تحت مسار فرعي يحاكي GitHub Pages. فشل تشغيل المتصفح بسبب قيود النظام ليس نجاحًا للاختبار.

```sh
node scripts/serve-static.mjs
```

يفتح آخر أمر نسخة الإنتاج على `http://127.0.0.1:4173/mizan-test/`.

## GitHub Pages

1. استخدم مستودع المشروع المقصود، وارفع مصدر هذا المجلد دون node_modules أو ملفات محاسبية فعلية.
2. من Settings → Pages اختر Source: GitHub Actions. لا تغير خصوصية المستودع إلا بقرار صاحبه؛ إتاحة Pages تعتمد على الخطة ونوع المستودع.
3. سير العمل `.github/workflows/pages.yml` يختبر ويُنشئ الموقع ثم ينشره عند الدفع إلى main/master، أو بالتشغيل اليدوي.
4. النشر العام لموقع أعمال مدفوع مستقبلًا يحتاج مراجعة شروط GitHub Pages وملاءمة الاستضافة. النسخة الحالية أداة تجريبية ثابتة بلا تحصيل مدفوعات.
5. الأصول نسبية لتعمل عند جذر الحساب أو تحت `/repository/`. مخرجات النشر في `dist` فقط.

## الخصوصية

لا backend مالي، ولا telemetry، ولا خطوط خارجية. العامل المحلي يحمّل قبل اختيار البيانات ويظل جاهزًا للمقارنة والتصدير. لا تُحفظ المعاملات في التخزين المحلي؛ تعيين الأعمدة فقط اختياري. تنزيل Excel يحفظ المعلومات على جهازك حيث تختار.

تُضاف CSP إلى نسخة البناء وتمنع اتصالات التطبيق المباشرة. GitHub Pages لا يسمح بضبط كل رؤوس HTTP؛ لا ندّعي عزلًا أمنيًا كاملًا للعامل أو تحكمًا بسجلات المضيف. سياسة CSP ليست إثباتًا منفردًا للخصوصية.

## الحدود

- 8 MB لكل ملف، 100 عمود، نحو 20,000 صف، 12 ورقة، ومليون خلية للمصنف كاملًا؛ رفض بدل اقتطاع صامت.
- ملفات XLSX المشفرة وذات روابط خارجية/ماكرو مرفوضة. الصفوف ذات الصيغ تتطلب نسخة قيم موثوقة أو استبعادًا صريحًا.
- CSV بترميز UTF-8 وفاصلة/فاصلة منقوطة/Tab، بلا تنفيذ نصوص كصيغ.
- اتجاه الإشارات ونوع التقرير والنطاق يؤكدها المستخدم. لا ادعاء بفهم آلي عام للملفات.
- مطابقة آلية لمرجع أصلي متطابق يحوي أحرفًا وأرقامًا وغير مكرر في أي طرف، ومبلغ موقّع مطابق ضمن نافذة تاريخ. توحيد الفواصل والرموز يولّد مرشحين للمراجعة فقط. المراجع الرقمية فقط للمراجعة.
- PDF النصي متاح ضمن [حدود القراءة والمراجعة](docs/PDF.ar.md)، دون صور أو OCR. لا N:M ولا تخصيص دفعات ولا ترحيل قيود.
- إعادة فتح الموقع دون اتصال غير مدعومة؛ التشغيل المحلي بعد تحميل المحرك متاح. العامل مضمّن مع الصفحة ويمكن إعادة إنشائه من النسخة المحملة بعد الإلغاء.

`examples/` يحتوي بيانات اصطناعية فقط. لا تستخدمه دليلاً على دقة ميدانية.

## المساعد المحلي وAI — الإصدار 0.2

«اسأل عن النتيجة» يشرح الأرقام من نتيجة المحرك ويذكر صفوف المصدر. لا تخرج منه قرارات مطابقة. تمسح المحادثة عند تغيير النتيجة ولا تُخزن على الخادم أو في التخزين المحلي.

الأسئلة غير المفهومة يمكن توجيهها إلى Prompt API في المتصفح فقط إذا أعادت حالة `available` لنفس لغات الإدخال/الإخراج (العربية والإنجليزية). لا يوجد اتصال بنموذج سحابي أو مفتاح API أو تنزيل يبدأه التطبيق. إن لم يتوافر النموذج، يبقى مساعد القواعد ويصرّح بحدوده. لا نضمن توفر النموذج أو اللغة على كل جهاز.

مخرجات النموذج JSON محدودة: نوع السؤال، معرف حركة، ومعرفات اقتراح اختياري. يُرفض أي حقل أرقام أو اعتماد أو نص حر. المحرك يعيد اختبار معرفات الحركات والمبالغ والإشارات وعدم إعادة الاستخدام. تساوي المجاميع وحده يبقي الفرضية للمراجعة. الأسئلة والنتائج لا تُعامل كتعليمات تنفيذ.

توثيق واجهة المتصفح: https://developer.chrome.com/docs/ai/prompt-api

قبل كل تصدير، يعاد بناء النتيجة من ملفات المصدر وتعيين الأعمدة والقرارات. يرفض التصدير النتيجة المختلفة، وتضاف ورقتا Diagnostics وMatch evidence للتدقيق.

## تحديث 0.3

أُصلحت قراءة أرقام Excel الأصلية وإسناد مراجع الشات، وأضيف تحقق فعلي لفك الضغط، وبصمات الملفات وإعادة قراءتها من أصلها قبل التصدير، ومراجعة الطرفين وسجل قرارات وحفظ/استعادة جلسة محلية. ملف الجلسة يتضمن البيانات دون تشفير؛ لا تشاركه كمستند عام.

المساعد العربي يعتمد القواعد. لا يستدعي التطبيق نموذج العربية غير المدعوم. لا يوجد نموذج عربي توليدي مثبت. العامل الحالي Blob مضمّن تحت CSP الصفحة، بدل ملف عامل مستقل.

فحص الإنتاج الحالي: صفر تنبيهات تبعيات، و68 اختبارًا ناجحًا. تفاصيل الشروط والحدود في [تقرير إغلاق التدقيق](audit/RESOLUTION-0.3.ar.md). متطلبات 0.2 الموضحة أعلاه تاريخية فيما يخالف هذا التحديث.
