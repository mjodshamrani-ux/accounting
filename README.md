# تَـراصُـف — تسويات محلية

**تطوّر المشروع في السحابة أو تبدأ العمل عليه؟** ابدأ من [بوابة مرجعية تراصف](docs/README.ar.md): الرؤية، الحالة المثبتة، الهيكلة، الهوية، تاريخ القرارات، وخطة مستقلة لكل نوع تسوية. تعليمات المساهمين في [AGENTS.md](AGENTS.md)، ومدخل Claude في [CLAUDE.md](CLAUDE.md)، والعمل التالي في [الخطة الحالية](docs/CURRENT-PLAN.ar.md).

نسخة تجريبية بالعربية والإنجليزية، إصدار الحزمة 0.4.58؛ الإصدار المنشور وحالته في [جدول الحالة](docs/reference/STATE.ar.md#الحالة-الحالية). تُقرأ المصادر وتُراجع وتُقارن وتُحفظ الجلسات وتُصدّر أوراق Excel على الجهاز. لكل مجال عقد محدود؛ نجاح المقارنة لا يثبت اكتمال نظام محاسبي أو أصالة المصدر أو دقة ميدانية عامة.

تشمل الواجهة الموردين، المقاصة، العملاء، GL/TB، تخصيص الدفعات، البنك، TB والقوائم، الشركات الشقيقة، بوابات الدفع، المخزون، الأصول والرواتب. تعيد مسارات القرار والاستعادة والتصدير التحقق من أدلة المصدر؛ لا يكفي تساوي المجاميع لإثبات علاقة محاسبية.

يوحّد إصدار 0.4.48 تجربة الرفع بالرسم التفاعلي الأصلي في كل مساحات العمل. تبقى المقدمة والمميزات والخطوات والخصوصية متاحة عند التنقل بين الأنواع، وتحمل أوراق المشهد الرئيسي تسميات عامة للسجلات. تظل صيغ الملفات والمصادر المطلوبة والقراءة والنتائج خاصة بعقد كل تسوية، دون إضافة إعدادات أو تأكيدات جديدة. [تفاصيل الإصدار](docs/RELEASE-0.4.48.ar.md)

يعيد إصدار 0.4.47 خط ثمانية الأصلي للعناوين العربية والشعار، مع تصريح استضافة أكدّه صاحب المشروع وملف مصدر وبصمة محفوظين. يجمع الأنواع الاثني عشر في اختيار واحد فوق مساحة العمل، ويبدأ بالمصادر الرئيسية ثم يكشف المستندات المطلوبة وبيانات النطاق عند الحاجة. الخيارات الإضافية مطوية، وبيانات كل مساحة تبقى عند التنقل بين الأنواع. [تفاصيل الإصدار](docs/RELEASE-0.4.47.ar.md) · [عقد الواجهة والخط](docs/WORKSPACE-IDENTITY.ar.md)

إصدار 0.4.39 يحمي ظهور أدلة XLSX عند إعادة القراءة والحفظ والاستعادة والتصدير، ويحافظ على البايتات والبصمة وجرد الصفوف. تفحص العائلات المرنة الورقة والخلايا المختارة؛ تبقى الأوراق المساعدة غير المختارة وحدود العناوين المدمجة والصيغ غير المستخدمة وفق العقد السابق. تمنع أبعاد العرض الصفرية والخطوط غير الظاهرة اعتماد نتيجة نظيفة؛ يحتفظ المورد بالصف المخفي ومبلغه مع التحذير والمراجعة. يعيد فحص العرض بناء تنسيق الأرقام الموروث من بايتات المصدر، ويتحقق من اللون في قسم التنسيق الفعّال دون إعادة تفسير مبالغ أو تغيير قيم ومعرّفات. يستخدم فحص اللون تباينًا لا يقل عن 3:1 بين النص وخلفيته، ويشخّص الألوان أو الخلفيات التي لا يمكن تفسيرها بأمان بدل تخمين ظهورها. هذا نطاق عرض محدود، وليس شهادة لكل تنسيقات Excel أو لأصالة البيانات. تبقى الأموال النصية والرقمية ودقة العملة ضمن سياسة كل محرك، وحارس البنك الأصلي الأضيق قائمًا.

[النطاق والحدود](docs/PRODUCT-SCOPE.ar.md) · [خطة المتابعة](docs/CURRENT-PLAN.ar.md) · [سياسة المصدر العام](docs/PUBLIC-SOURCE-POLICY.ar.md)

تظهر ورقتا نسخ المصدر الحرفية للمورد والدفتر في التصدير، لتبقى إعادة استيرادهما خاضعة لفحص الظهور نفسه دون استثناء للأوراق المخفية.

## تشغيل محلي

Node 24.19.0 وpnpm 11.19.0:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

```sh

pnpm test

pnpm build
pnpm exec playwright install chromium
```

يشغل سير العمل أيضًا مدققات Python مستقلة واختبارات العقود والأدلة المالية. تحتاج اختبارات الواجهة Chromium وبيئة تسمح بخادم محلي. عدم إمكان تشغيل الاختبار ليس نجاحًا له. لا يجوز نسبة نتيجة تاريخية إلى هذا المرشح دون إعادة التحقق.

## الخصوصية والنشر

لا backend مالي أو telemetry أو خط خارجي. تُحمّل أصول البرنامج وOCR الثابتة من نفس الموقع؛ لا تتضمن طلباتها محتوى الملف المالي. تضاف CSP إلى البناء. ملفات الجلسة وأوراق Excel المنزلة تحتوي بيانات المستخدم دون تشفير ويختار المستخدم مكان حفظها محليًا.

مصدر النشر العام قائمة محددة من الشفرة والعينات الاصطناعية والأصول العامة المراجعة. لا تدخل الأصول الميدانية أو تقارير المستخدم أو سجلات الجهاز أو أرشيفات المراجعة المحلية في هذه القائمة. لا تُرفع مجلدات نتائج الاختبارات الخام كأدلة عامة في CI. يراجع حارس المحتوى المصدر وحزمة `dist` قبل رفع حزمة Pages.

النشر مشروط بالمراجعة المستقلة ونجاح جميع فحوص الرأس النهائي وثبات المرشح و`main`، ثم فحص الموقع الحي. حذف ملفات من رأس المصدر لا يمحو نسخها القديمة من تاريخ Git أو تنزيلات الآخرين؛ معالجة التعرض التاريخي عمل منفصل.
