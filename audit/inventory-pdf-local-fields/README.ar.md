# INV-1F-G2 أدوار حقول PDF وحدودها المحلية

[العقد](contract.json) و[تقرير التنفيذ](../../docs/audits/INV1-PDF-LOCAL-FIELDS.ar.md) يفصلان إثبات دور الحقل وملكيته عن صحة الحساب والمطابقة. لا يفعّل هذا الجزء PDF ماليًا في المخزون.

يبدأ readInventoryPdfRegister من البايتات الأصلية عبر حراس G1، ثم يقرأ رؤوس كل جدول في صفحتها. يحتفظ كل اقتباس ببصمة الأصل والصفحة والسطر وعناصر النص والصندوق وطريقة تجميع النص. لا تستخدم قيمة text المجمعة عبر فجوات بوصفها هوية مالية حرفية؛ gap-presentation تعني حاجة إلى إثبات إضافي من الأصل. يحفظ جرد كامل النصوص غير المفسرة بدل إسقاطها.

تشغيل الأجزاء مستقل:

- pnpm test:inventory-pdf:fields-proof
- pnpm test:inventory-pdf:fields-mutations
- اختبارات tests/inventory-pdf-register.test.ts ضمن pnpm test

يولد المسبار مصادر الأساس المختومة نفسها، ويقرأ 19 PDF فعليًا ثم يفحصها مدقق Python مستقل. يراجع النص الهندسي أولًا، ثم أدوار الحقول والأب والدفعة والنطاق وحدود القسم والاستمرار، بما فيها اقتباس صحيح النص من صفحة خاطئة. المدقق لا يستورد منتج التطبيق أو مولد المصدر. تحفظ مخرجاته داخل work أو مسار INV_PDF_FIELDS_PROOF_DIR، والطفرات في INV_PDF_FIELDS_MUTATION_DIR. لا ترفع القراءات والمصادر المولدة أو سجل الجهاز.

N09 وN12 صحيحتان في توزيع الأدوار، لكنهما خاطئتان ماليًا وفق أوراكل الأساس المحفوظ: إجمالي صفحة غير صحيح ودقة لا تمثل الكمية. يجب أن تمنعهما G3 دون إصلاح صامت؛ لا يحتسب نجاح G2 فيهما نتيجة محاسبية صحيحة.
