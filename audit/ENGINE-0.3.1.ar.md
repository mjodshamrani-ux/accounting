# تدقيق المحرك 0.3.1 — 9 سبتمبر 2026

هذه جولة للمحرك وقارئ الملفات وحدود AI. الحالات اصطناعية، وليست Holdout محاسبيًا مستقلًا أو إثباتًا لدعم جميع قوالب الموردين.

## التحقق

- 167 اختبارًا: 102 سابقًا و65 إضافية.
- 48 حالة كاملة للاستيراد والتسوية وتصدير Excel وإعادة فتحه: CSV/XLSX، العربية والإنجليزية، ترتيب أعمدة مختلف، مقدمات وعناوين متكررة مستبعدة بسبب صريح، مبلغ موقّع أو مدين/دائن، نقطة أو فاصلة عشرية، ودقة 0/2/3. النتائج المتوقعة مبالغ صحيحة مكتوبة مسبقًا. هذه تركيبات اصطناعية وليست 48 موردًا فعليًا.
- حدود نافذة التاريخ في الاتجاهين حول السنة الجديدة والسنة الكبيسة وللنوافذ 0/1/2/7 أيام.
- 26 مجموعة PDF تشمل ملفات فعلية واختبارات الظهور والقص والأقنعة والرسوم والمصادر والتصدير.
- فحص 18 ملف Excel و288 خلية رقمية بأداة Python مستقلة عن ExcelJS؛ تنسيقات ونصوص عربية وإنجليزية وCRC وXML، دون صيغ.
- Mutation Testing: سبعة أخطاء مقصودة في نسخ مؤقتة معزولة يجب أن تفشل بتأكيدات الاختبارات، لا بأخطاء تشغيل أو SyntaxError. تشمل الإشارة والمرجع والتاريخ والتكرار والتغطية وصلاحية AI ومبلغ التصدير. أضيفت البوابة إلى GitHub Actions قبل النشر.

فحص الأنواع والبناء والاختبارات البرمجية والضغط والبوابة والفحص المستقل تُسجل محليًا. نتائج اختبار Chromium والنشر متاحة في [GitHub Actions](https://github.com/mjodshamrani-ux/accounting/actions). لا ينشر سير العمل إذا فشلت إحدى بواباته.

## الفشل والحدود

أُعيد إنتاج عيوب AI والتأكيدات والاستبعادات وتنسيق Excel والجمع ورسوم PDF قبل الإصلاح. سجلاتها المحلية: `audit/assistant-adversarial-before.txt` و`audit/file-core-adversarial-before.txt` و`audit/exact-sum-before.txt` و`audit/pdf-adversarial-before.txt`. هذه الحالات أصبحت Regression Tests؛ لم تتحول إلى Holdout مستقل.

صُحح إعداد اختبارين: عمود المبلغ المتوقع في مصنف التصدير كان السادس بدل الثامن، وأحد مستطيلات PDF المحولة كان خارج الرقم المقصود. هذان خطآن في العينات وليسا عيبين في المحرك. المجموعة المختارة لبوابة Mutation Testing احتاجت حالة صريحة لحدود التاريخ فأضيفت؛ اختبارات الضغط السابقة تختبر التاريخ أيضًا.

لا OCR، ولا دعم عام لكل تنسيق Excel أو كل PDF. منع التنسيق الشرطي محافظ على مستوى الورقة. فحص رسوم PDF محافظ وقد يرفض جدولًا صحيحًا تتداخل الحدود المجمعة لرسوماته مع النص؛ لا يثبت تطابق كل بكسل أو دعم كل خط عربي. مراجعة الأصل والنطاق والإشارات تبقى شرطًا.

المساعد العربي يعتمد قواعد المحرك، ولم يُختبر نموذج محلي فعلي. لا يُستخدم AI لفهم ملف مجهول ثم اعتماده. دعم قالب جديد يحتاج نموذجًا ونتيجة مرجعية من محاسب واختبارًا مستقلًا. تساوي الأرقام لا يثبت أصالة المستند أو العلاقة الاقتصادية.

إصدار المحرك `0.3.1-experimental`. الجلسات المحفوظة بإصدار مختلف لا تستعاد تلقائيًا؛ يُعاد رفع المصادر لتطبيق الضوابط الجديدة. تبقى أوراق العمل القديمة بنتائج وإصدارات إنشائها.
