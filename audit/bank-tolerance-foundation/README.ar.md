# أساس TOL-1: السماحية المعلنة في كشف البنك

حزمة مصدر وتقييم قبل أي دعم في المنتج، لبند [TOL-1](../../docs/roadmap/workflow.ar.md) في WF-1 و[CH-16](../../docs/reference/CHALLENGES.ar.md). التقرير في [`docs/audits/WF-1-TOL-FOUNDATION.ar.md`](../../docs/audits/WF-1-TOL-FOUNDATION.ar.md). كلها مصطنعة.

## لماذا

- **فرق هللة بين حركة الكشف وقيدها تحت المرجع نفسه يبقى استثناءً لا يُقبل:** سببه `amount-difference`، ولا يملك المحاسب إلا رفضه فيبقى البندان معلقين، أو تركه فتبقى الورقة مسودة.
- **والخطر في الحل:** سماحية تصنع زوجًا لم يثبته مرجع، أو تختار بين مرشحين، أو تصفّي فرقًا موجبًا بفرق سالب، أو تغير مبلغًا، أو تُخفي من الورقة فرقًا لم يُفسَّر.

## ما في الحزمة

| الملف | دوره |
|---|---|
| [`contract.json`](contract.json) | العقد المقترح `bank-tolerance-1`: السياسة وصحتها ورفضها، والأهلية، وقاعدة الفترة، والحالة المسموحة، والقرارات وسياقها، والجلسة والمصنف، والورقة بقسمها وحالتها، وسبعة قرارات لصاحب المشروع |
| [`stories.mjs`](stories.mjs) | 23 قصة على ديسمبر 2026، فترة لكل قصة، كل منها بالريال إلا واحدة بالدينار الكويتي بثلاث منازل، وما يفعله المحاسب بالترتيب: يعلن سياسة، أو يرفض حالة، أو يتراجع |
| [`render.mjs`](render.mjs) | يطبع الكشوف بـChromium بقالب أساس كشف البنك، والمبالغ بمنازل عملتها، ويكتب الدفاتر CSV |
| [`oracle.py`](oracle.py) | أوراكل مستقل يسوي الفترة بنفسه بوحدات صغرى صحيحة بمنازل العملة، ثم السياسة والقرارات والورقة. لا يقرأ الوصفة ولا النية، ولا يستورد المولد أو المنتج |
| [`test_oracle.py`](test_oracle.py) | 7 اختبارات: النية في كل قصة، وعدم قراءة الوصفة والنية، و**تسوية كل فترة بمنزلتين كما يسويها [أوراكل ROLL-1](../bank-roll-foundation/oracle.py) المختوم**، وأن ما يُسمح به فرق مبلغ وحده بلا تغيير في الأعضاء أو المبالغ، وأن الفرق يساوي المسموح مع الباقي |
| [`mutate_oracle.py`](mutate_oracle.py) | 16 عيبًا مزروعًا في نسخة من الأوراكل؛ كل كشف فشل تأكيد |
| [`verify.py`](verify.py) | قراءة مستقلة لكل PDF بـpdfminer.six عبر فاحص ROLL-1 المختوم كما هو، والكشف بالدينار بالفاحص نفسه ومبالغه بثلاث منازل؛ وستة تغييرات مزروعة يجب أن تُرفض |
| [`seal.py`](seal.py) و[`check_seal.py`](check_seal.py) | الختم وفحصه في CI، ويعيد `stories.mjs` الحقائق بايتًا ببايت |

## القصص

| القصة | ما تختبره | المتوقع |
|---|---|---|
| T01 | فرق هللة، وسياسة هللة للزوج وخمس للفترة | مسموحة؛ الورقة مسواة ضمن السماحية |
| T02 | فرق هللتين | خارجها؛ تنتظر قرارًا |
| T03 | فرق عند الحد بالضبط | مسموحة |
| T04 | فرقان من الجهة نفسها مجموعهما فوق حد الفترة | لا يُسمح بأي منهما |
| T05 | فرقان متعاكسان صافيهما صفر | لا يُصفّيان: لا يُسمح بأي منهما |
| T06 | T04 بحد فترة يسعهما | مسموحتان |
| T07 | دينار كويتي: فرق فلس داخلها وعشرة فلوس خارجها، والثاني مرفوض | الأول مسموح، والورقة مسواة ضمن السماحية |
| T08 | T01 بلا سياسة | كما المنتج اليوم |
| T09 | حركة وقيد بلا مرجع بينهما هللة | لا زوج: السماحية لا تصنع زوجًا |
| T10 | تعارض اتجاه | يبقى تعارضًا |
| T11 | مرجع مكرر | يبقى مجموعة مراجعة |
| T12 | فرق هللة وتاريخان أبعد من النافذة | لا يُسمح |
| T13 | رفض حالة مسموحة | بندان معلقان |
| T14 | الرفض ثم التراجع | مسموحة من جديد |
| T15 | تغيير السياسة بعد قرار | `BANK_STATEMENT_DECISION` |
| T16 | سياسة ريال للزوج | `TOLERANCE` بقاعدة `PER_ITEM` |
| T17 | حد فترة أقل من حد الزوج | `PER_PERIOD` |
| T18 | سياسة بلا ملاحظة | `NOTE` |
| T19 | كشف عربي على ثلاث صفحات، وثلاثة فروق حتى حد الفترة | الثلاثة مسموحة، وأثرها الصافي صفر |
| T20 | قيد بالمرجع بفرق هللة، وقيد بلا مرجع بالمبلغ نفسه تمامًا | يُسمح بالقيد ذي المرجع؛ ويبقى الآخر معلقًا |
| T21 | أربعون زوجًا عاديًا وخمسة فروق | مسموحة كلها |
| T22 | سياسة ولا شيء يُسمح به | مسواة |
| T23 | فرق هللة ورصيد دفتر معلن ينقص 50.00 | الهللة مسموحة، والـ50.00 باقية بلا تفسير |

**في المتوقع 16 حالة مسموحة، و8 فروق مبالغ تبقى، وحالتان تجاوز فيهما المجموع حد الفترة، وأربعة رفوض.** والسماحية لا تغير مبلغًا، ولا تصنع عضوًا أو تنقله، ولا تقرر حالة، ولا تُخفي فرقًا.

## الحدود

- **كتبتُ القصص والنية والأوراكل والعقد بنفسي.** والاستقلال المختبر: الأوراكل لا يقرأ الوصفة ولا النية ولا يستورد المولد أو المنتج، ويوافق أوراكل ROLL-1 المختوم في تسوية كل فترة بمنزلتين؛ والتحقق بقارئ PDF آخر.
- **فترة واحدة لكل قصة، بلا حالات مرحّلة،** وكشوف PDF مطبوعة بقالب واحد هو قالب أساس كشف البنك.
- **الريال والدينار الكويتي وحدهما.** والدينار في قصة واحدة.
- **العقد مقترح،** وفيه سبعة قرارات لصاحب المشروع، وليس رأيًا محاسبيًا مهنيًا في أي سماحية مقبولة.
