# قبول واجهة PDF المخزون باللغتين

هذه الحزمة تحقق [G5b](../../docs/audits/INV1-PDF-WORKSPACE.ar.md) فوق G4 وG5a. لا تحتوي أصولًا مالية حقيقية ولا تعيد توليد أو تعديل أساس INV-1F المجمد. [العقد](contract.json) يحصر الادعاء في عائلتي PDF وأربعة عروض موجبة لقصة اصطناعية معروفة، وليس أربع عائلات أو holdout.

- `pnpm test:inventory-pdf:workspace`: الالتقاط والحارس والمساعد واللغة وحماية الرد القديم
- `pnpm test:inventory-pdf:workspace-proof`: 39 مرحلة من 19 حالة عبر العامل، و78 صادرًا باللغتين مع مقارنة OpenXML وحقائق المصدر المستقلة، وضوابط الصادر الإنجليزي والعربي
- `pnpm test:inventory-pdf:workspace-mutations`: ثماني طفرات، لا يعد فشل التجهيز أو timeout قتلًا
- `pnpm test:inventory-pdf:workspace-browser`: رفع حقيقي من الواجهة والعامل المبني، تأكيد ومراجعة وقرار وتراجع ورفض وإعادة فتح وحفظ واستعادة ومساعد وتبديل لغة وإلغاء رد متأخر

يعتمد `check_workspace.py` على قارئ OpenXML وحراس الأصل في G5a، ثم G3 والأوراكل المالي والمصدر المجمد. `labels.ar.json` توقع مستقل لأسماء العرض فقط؛ لا تؤخذ منه قيمة مالية أو كمية أو عضوية. يزيل المدقق تسميات العرض المصرح بها وحدها، ويبقي البايتات والحروف والأصفار والأبعاد والروابط والقرارات بلا ترجمة. يجب تطابق جميع الجداول بين اللغتين بعد هذه الخطوة، وتكون أوراق العربية RTL. لا يقبل الاستدلال من تساوي الإجمالي.

تجرب ضوابط العربية تبديل قيمتين مع بقاء الإجمالي، وتحريف الكمية والبعد والربط والرأس واتجاه الورقة وأصل المصدر والدليل والاعتماد والصيغة. يقبل ضابط إعادة كتابة سليم؛ يلزم AssertionError من الحارس المقصود لكل تحريف، لا خطأ بيئة. تحفظ الملفات والصور والجلسات والتقارير محليًا في work ولا ترفع ضمن المصدر العام.

المساعد المقاس هنا حتمي للشرح، وليس نموذج ذكاء جديدًا. تعاد قراءة الأصول قبل الإجابة والتصدير والاستعادة، ولا تنشئ الإجابة قرارًا. نجاح عارض الهاتف لا يثبت قدرة CPU أو RAM لجهاز فعلي ضعيف. لا قياس جديد لسعة PDF المخزون ولا تفعيل للصور الممسوحة في هذه الدفعة.
