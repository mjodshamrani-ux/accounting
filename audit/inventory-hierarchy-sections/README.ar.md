# حزمة INV-1D لرؤوس أبعاد المخزون

حزمة تطوير اصطناعية لعائلة `inventory-hierarchy-sections-1`. تثبت مصدر السجل الأول في CSV أو ورقة Excel أصلية واحدة، مع ثلاثة مصادر CSV للخريطة والسياسة وGL. ليست holdout أو تجربة عميل أو دعمًا عامًا لكل رؤوس التقارير.

تبدأ العائلة بعنوان `Inventory carrying-value register` و12 حقيقة نطاق باسم وقيمة، ثم قسم `Warehouse` أو `Plant` ودفعة `Batch` وترويسة تفصيل. يدعم العقد الأول أسماء الحقول الإنجليزية المعلنة؛ الواجهة والمساعد يعملان بالعربية والإنجليزية. لا يحتاج الملف إلى سطر `Format` خاص بتراصف.

- ستة حقول تفصيل بأي ترتيب، أو سبعة مع `Item dimensions` صريح مطابق للرؤوس
- عدة أصناف في الدفعة، وترويسة مكررة، وفراغات، وضوابط مجاميع، وحدود من الرأس التالي أو نهايات صريحة
- تغيير الأب يلغي الدفعة والترويسة، وتغيير الدفعة يلغي الترويسة، والصف غير المفهوم يلغي سلطة الدفعة
- دمج أفقي B:F أو B:G في قيمة رأس المصنع/المستودع/الدفعة فقط، مطابقًا لعرض حقول التفصيل؛ لا دمج مالي أو رأسي أو حمولة مخفية في الخلايا المغطاة
- كل بُعد مشتق معلن له خلية اسم وقيمة ومدى دمج وحدود ملكية فعلية؛ لا يقدم النص المركب كأنه خلية أصلية

## مصادر ودليل

قصة SAR جديدة واحدة، وعائلة تفاصيل هرمية واحدة، و18 حالة (6 جاهزة وفرق ونقص دليل و10 أخطاء مصدر)، و72 أصلًا: 63 CSV و9 XLSX. ملفات Excel تكتب بـOpenXML صريح باستخدام مكتبة Python القياسية. تبديل الحاوية أو ترتيب الأعمدة ليس قصة إضافية. قائمة المدخلات تثبت 73 ملفًا تشمل corpus؛ لا يتغير الأصل أو الأوراكل السابق INV1A/B/C.

يؤلف `generate.py` الأصول دون استيراد المنتج أو الأوراكل. يفحص `oracle.py` CSV وXML وDecimal، ويحدد مواقع الحقول وحدود الأقسام، ثم الربط بالخريطة والسياسة وGL. الحقيقة المالية الثابتة مستقلة عنهما: 5 أصناف/أبعاد بقيم 40000 و60000 و100000 و25000 وصفر، ومجموع 225000 بوحدات SAR الصغرى. تبديل أول قيمتين يبقي إجمالي الحساب والإجمالي العام صحيحين ويكشف فرقَي أبعاد +20000 و-20000.

`test_oracle.py` يفحص الفاحص نفسه. كشف تشغيله الأول خطأ إسناد الترويسة إلى «الصف السابق» عند تعدد التفاصيل؛ أصلح موقع الترويسة النشطة قبل تقييم القارئ، وبقيت الحقائق والأصول ثابتة. الفحص النهائي 7/7. `check_export.py` يقرأ Excel مستقلًا من OpenXML ويثبت السجلات والكمية والأبعاد والخرائط والسياسات وGL والخلايا والاستشهادات والبايتات والأحداث. قارئ المخرج محمول من قارئ INV1C المدقق مع عقد تحقق خاص بهذه العائلة.

أُضيفت اختبارات انحدار تحويلية لانتقال ضمني إلى أب بلا دفعة، وصفر مكرر، وصف بعد نهاية دفعة، ومفتاح `Plant` الصريح، وترويسة مكررة بين طفلين فعلًا. حالة P06 المجمدة تضع ترويسة إضافية في آخر الدفعة؛ لا نعدها وحدها دليلًا على التكرار بين طفلين.

## التشغيل

تستخدم بيئة المستودع المثبتة. لا يلزم تنزيل مكتبات توليد Excel أو نماذج أو الاتصال بمزود مالي.

```sh
pnpm test:inventory-hierarchy
pnpm test:inventory-hierarchy:oracle
pnpm test:inventory-hierarchy:proof
pnpm test:inventory-hierarchy:mutations
pnpm build
pnpm test:inventory-hierarchy:browser
```

تكتب الأصول الناتجة والصادرات والتحويرات والسجلات في `work` محليًا أو مجلد الاختبار المؤقت. لا ترفع هذه المخرجات الخام إلى GitHub. الحالة والدليل وحدود المرشح في [تقرير التنفيذ](../../docs/audits/INV1-HIERARCHY-SECTIONS.ar.md).
