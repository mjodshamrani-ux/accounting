# دليل G3 المستقل

العقد والشفرة هنا آمنان للنشر. تبقى الأصول المصطنعة وقراءات JSON وسجلات الطفرات في work أو مجلد مؤقت خاص، ولا ترفع إلى المستودع. لا تستعمل ملفات المستخدم في حزمة اختبار عامة.

- [العقد](contract.json) يثبت نتائج G3 وحدود التفعيل
- [المدقق](check_result.py) يقرأ PDF/CSV الأصليين ويحسم الحروف والأرقام والأعضاء بـDecimal دون استيراد المنتج أو المولد
- [التقرير](../../docs/audits/INV1-PDF-ACCOUNTING.ar.md) يفصل التنفيذ والقياس والحدود

الأوامر: pnpm test:inventory-pdf:accounting ثم pnpm test:inventory-pdf:accounting-proof ثم pnpm test:inventory-pdf:accounting-mutations. يحتفظ foundation بالأصول المختومة ومولدها وأوراكلها كما كانت. لا تضع أرقامًا متوقعة مأخوذة من نتيجة المحرك، ولا تصلح الأوراكل ليقبلها.

هذه ليست بوابة لتفعيل PDF في Worker أو الجلسة أو التصدير. المسار المالي يقبل الأصول الأربعة وحدها، ويحفظ المراجع ولا يقبل cache جاهزًا أو اعتمادًا من AI. التفسير الحرفي الجديد محدود بالنص LTR والعائلة المعرفة، ولا يدعي قراءة كل تقرير مخزون أو OCR.
