# دليل Excel للمخزون PDF

هذه حزمة **INV-1F-G5a** لسلامة الصادر، لا عائلة ملفات جديدة أو تفعيل رفع PDF في الواجهة. تعيد استخدام أصول [INV-1F المختومة](../inventory-pdf-foundation/README.ar.md) و[دورة G4](../inventory-pdf-lifecycle/README.ar.md). القصة معروفة للمطور: عائلتا PDF وأربعة عروض موجبة و19 حالة PDF، وليست عينة ميدانية أو holdout جديدًا.

[العقد](contract.json) يثبت المدخل وحدود السلطة. ينشئ [المسبار](../../scripts/inventory-pdf-workbook-proof.mjs) 39 ملف Excel عبر Worker فعلي، تشمل المقارنة غير المعتمدة والتأكيد المحدد والقبول والتراجع والرفض وإعادة الفتح في الموجبات، والفروق ونقص الدليل وأخطاء المصدر في بقية الحالات. لا يعاد تفسير PDF كملف CSV أصلي، ولا تقبل نتيجة قديمة كمرجع مالي.

[المدقق](check_export.py) يقرأ OpenXML بأداة قائمة من الأساس دون مكتبة المنتج، ويفحص الحقائق والملكية والروابط بأوراكل G3 وDecimal من الأصول نفسها. يقارن كل جدول، بما فيه المبالغ والكميات ودقتها والأبعاد والصفحة والسطر والحروف والقرار والأعضاء والأصول الأربعة الكاملة. يفحص الجرد غير المحسوم أيضًا داخل دليل PDF المجزأ دون حذف أو تجاوز حد خلية Excel. لا ينفذ صيغة أو رابطًا خارجيًا.

```sh
pnpm test:inventory-pdf:workbook
pnpm test:inventory-pdf:workbook-proof
pnpm test:inventory-pdf:workbook-mutations
pnpm build
pnpm test:inventory-pdf:workbook-browser
```

تختبر ضوابط المدقق إعادة كتابة XLSX سليمة، و14 تحريفًا محددًا: تبديل مبالغ مع بقاء مجموعها، كمية أو أبعاد أو مرجع أو صفحة أو رابط خاطئ، إسقاط صفر بادئ أو أصل أو جزء دليل، اعتماد غير مستحق أو إجمالي صفحة خاطئ أو صيغة أو صف مخفي. لا تحتسب المهلة أو انهيار التجهيز رفضًا ناجحًا. تحفظ المخرجات الخام في `work` الخاص، ولا ترفع إلى المصدر العام.

فحص المتصفح يشغّل العامل المضمن الفعلي من حزمة الإنتاج تحت CSP نفسها، ويعيد فحص الصادرات الـ39 مستقلًا. هو مسبار خلفي للعامل؛ لا يضغط زر رفع PDF في واجهة المحاسب ولا يثبت اكتمال G5. تظل واجهة PDF والمساعد وعرض المصدر والتصدير العربي وقياس عبء المراجع والتسليم الحي أعمالًا لاحقة موثقة في [تقرير الوحدة](../../docs/audits/INV1-PDF-WORKBOOK.ar.md).

تضاف أربعة ضوابط على تقرير الأدلة نفسه: عملة أو دقة مخالفة، وتأكيد نطاق أو اكتمال رقمي بدل Boolean. تفشل عند حارس المرجع الأصلي حتى مع تحديث سياق التقرير ليتسق مع التحريف؛ لا تعتمد على اختلاف ملف Excel وحده. تظل ضوابط XLSX الأربعة عشر منفصلة عنها.
