# أساس AR-1 بصيغة PDF: كشف العميل كما تطبعه الشركة

حزمة مصدر وتقييم قبل أي دعم في المنتج. التقرير في [`docs/audits/AR-PDF-1-FOUNDATION.ar.md`](../../docs/audits/AR-PDF-1-FOUNDATION.ar.md). كلها مصطنعة.

## لماذا

- **عائلتا AR القائمتان تقرآن CSV وXLSX فقط:**
  - `ar-limited-1` تطلب النطاق على كل صف، وتعدّ صف عميل آخر خطأ.
  - و`ar-scope-details-1` تطلب كتلة `AR_SCOPE` واحدة بعلامات صريحة.
- **كشف العميل المطبوع يذكر العميل والحساب والعملة مرة لكل قسم،** لا على كل صف. والطباعة المجمعة تحمل عدة عملاء.
- والمقترح عائلة جديدة `ar-statement-pdf-1`، بعقدها في [`contract.json`](contract.json).

## ما في الحزمة

| الملف | دوره |
|---|---|
| [`contract.json`](contract.json) | العقد المقترح: الرأس، والأقسام وحدودها ووراثتها، والتفاصيل، واختيار النطاق، والأخطاء، والمطابقة، وثلاثة قرارات لصاحب المشروع |
| [`stories.py`](stories.py) | 19 قصة حقائق. كل صفحة بسطورها كما طُبعت: نص، أو سطر عناوين، أو قيم تحت عناوينها. لا يقول السطر ما هو |
| [`render.py`](render.py) | يطبع السطور نفسها بـReportLab، ويكتب الدفاتر بعائلة `ar-limited-1` |
| [`oracle.py`](oracle.py) | أوراكل مستقل بـDecimal ومكتبة Python القياسية: يقرأ السطور المطبوعة والدفتر والنطاق المؤكد فقط، ويستنتج الأقسام والنطاق والأخطاء بنفسه |
| [`test_oracle.py`](test_oracle.py) | 20 اختبارًا: الاتفاق مع النية، وعدم قراءة الوصفة والنية، وعبث يحرك الحكم كما يقول العقد |
| [`mutate_oracle.py`](mutate_oracle.py) | 17 عيبًا مزروعًا في نسخة من الأوراكل؛ كل كشف يجب أن يكون فشل تأكيد |
| [`verify_assets.py`](verify_assets.py) | قراءة مستقلة لكل PDF بـpdfminer.six، وسبع تغييرات مزروعة يجب أن تُرفض |
| [`seal.py`](seal.py) و[`check_seal.py`](check_seal.py) | الختم وفحصه في CI |
| [`frozen/`](frozen/INPUT-MANIFEST.json) | 19 كشف PDF، و19 دفتر CSV، والحقائق، و`EXPECTED.json` و`VERIFY.json` و`SEAL.json` |

## الإعادة

```sh
pnpm test:ar-statement:oracle
pnpm test:ar-statement:oracle-mutants
pnpm test:ar-statement:seal
# إعادة الطباعة والقراءة المستقلة (لا تُستعمل لتغيير أصول مختومة):
PYTHONPATH=<reportlab, arabic-reshaper, python-bidi> python3 -B audit/ar-statement-foundation/render.py <dir>
PYTHONPATH=<pdfminer.six> python3 -B audit/ar-statement-foundation/verify_assets.py <dir>
```

يعيد `render.py` الأصول الـ38 بايتًا ببايت بـReportLab 4.2.5، ويعيد `stories.py` الحقائق بايتًا ببايت.

## الحدود

- كاتب واحد ومنتج PDF واحد. هذا أساس تطوير، لا holdout.
- كتبتُ القصص والنية والأوراكل والعقد بنفسي. والاستقلال المختبر محدود بأمرين: الأوراكل لا يقرأ الوصفة ولا النية ولا يستورد المولد، والقراءة المستقلة لـPDF بمكتبة أخرى.
- العقد مقترح، وفيه ثلاثة قرارات لصاحب المشروع.
