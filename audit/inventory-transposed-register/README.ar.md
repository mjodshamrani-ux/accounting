# INV-1C دليل مصفوفات المخزون

حزمة تطوير اصطناعية لعائلة `inventory-transposed-register-1` وليست اختبارًا أعمى أو إثبات دقة ميدانية. تبدأ مصادر السجل بـ`Format,INV1A-MATRIX-1` وتوزع الحقول على صفوف والسجلات على أعمدة. هذا يغير طريقة الوصول إلى الحقيقة وربطها بالأصل، لا أرقام جدول الأقسام السابق وحدها.

## تنوع الهيكل

| الحالات | بنية الأصل | ما يجب إثباته |
| --- | --- | --- |
| P01 / P02 | محور Field واحد في CSV / Excel أصلي من xlsxwriter | أربعة سجلات منفصلة بأعمدة أصلية |
| P03 / P04 | كتل Field مكتملة متتابعة في CSV / Excel من openpyxl | كل حقل داخل كتلته وعموده رغم تكرار أسماء الأعمدة بين الكتل |
| P05 | عمود فاصل غير مسمى وفارغ داخل الكتلة | يبقى الفراغ فراغًا ولا يتولد سجل إضافي |
| P06 | ترتيب أعمدة وأدوار مختلف ومجموع تقرير مقدم | نفس الحقيقة مع إحداثيات مختلفة وفحص المجموع |
| N01 | تبديل قيمتين يبقي إجمالي التقرير وكل حساب صحيحًا | فرق أبعاد +86655 / -86655 دون اعتماد |
| N02 | تبديل أبعاد مع بقاء مراجع التقييم | missing؛ الدعم 333567 مقابل المقدم وGL667134 |
| N03–N08 | صفر مفقود، دور مكرر، مفتاح صنف مكرر عبر كتل، عمود مجهول يحوي صفرًا، كتلة ناقصة، رقم صنف عددي | source-error؛ لا أموال مقارنة أو إجماليات قابلة للاعتماد |

الجرد: قصة مالية جديدة واحدة بـKWD ودقة ثلاث خانات، عائلة مصفوفة دلالية واحدة، محور واحد أو كتل مكتملة أو فاصل فارغ، وترتيب تحويلي. ست حالات إيجابية وثماني سلبية،56 مصدرًا (50 CSV و 6 XLSX)، ومنتجان مستقلان للـExcel. اختلاف الحاوية أو تبديل ترتيب الصفوف ليس عائلة محاسبية أخرى.

## الحقيقة المستقلة

[العقد](contract.json) يثبت الأصناف `0014` و`014` و`14`، كميات KG بدقة 2 وEA بدقة 0، وقيمًا وأبعادًا ومراجع وخريطة وسياسة وGL لكل عضو. A+B=C في هذه القصة، ومجموعا الحسابين متساويان، ومع ذلك لا يقبل مجموع صحيح ربطًا بفرع آخر. لا تقارن كميات بوحدات مختلفة ولا تستخدم المال لإثبات كمية المصدر.

[المولد](generate.py) لا يستورد المنتج أو الأوراكل. مصادر Excel الأصلية من openpyxl3.1.5 وxlsxwriter3.2.9 محفوظة اصطناعيًا في [الأرشيف المثبت](xlsx-originals.json). يعيد المولد الافتراضي البايتات نفسها بلا تنزيل أو تثبيت منتج؛ إعادة إنتاج XLSX جديدة اختيار صريح لا يعيد كتابة الحزمة المجمدة.

[قائمة المدخلات](INPUT-MANIFEST.json) تحفظ 57 ملفًا تشمل الفهرس، وبصمتها `7abb94bbc3ad9fb1b3cfd080be2bf8db4fadc70dbf0a929c8206be461336f8e0`. [الأوراكل](oracle.py) يقرأ CSV وOPC/ZIP/XML بدقة Decimal مستقلًا؛ لا يستورد المحرك أو يتخذ ناتجه حقيقة. بقيت أصول INV-1A وأوراكلها وأصول INV-1B وحقائق المخزون القديمة ثابتة. P04 من INV-1A انحدار معروف بعد كشفه، وهذه القصة أيضًا أصبحت معروفة للمطورين.

## المخرج والقرار

Source row هو صف Item ID الحقيقي، وSource column عمود السجل الفعلي. سجل المصفوفة يملك ID بستة عناصر، وأعضاء المراجعة الفيزيائيون يحتفظون بـID الصف السابق دون تكراره لكل عمود. جدول Matrix citations يثبت لكل سجل قيمة الحقل ودور الحقل ومحور العمود وحدود الكتلة وأصل نطاق التقرير. تظل مصادر CSV وXLSX الأصلية مضمنة حرفيًا وبصماتها محفوظة.

[مدقق التصدير](check_export.py) يفحص الكميات والقيم والأبعاد والعضوية والإجماليات والخلايا ومراجع الحقول وحدود الكتل والأصول وسياق القرار. جرى اختبار أداة القياس بـ 17 مجموعة قبل تقييم المرشح، بينها تغيير كمية أو اقتباس خلية صفر من دور آخر مع بقاء الإجماليات صحيحة، وضوابط اعتماد وإلغاء وجلسة تنزيل فعلية. استخدام UUID والوقت الفعليين في المتصفح لا يعفي محتوى القرار من الفحص.

نجح أول دليل مرشح في 14 حالة و 20 تصدير Excel مستقلة: مباشر ومستعاد للإيجابيات وحالتي difference/missing، ثم اعتماد وإلغاء لـCSV وExcel. نجحت ست طفرات بإخفاقات assertions فعلية؛ لا يحسب timeout أو انهيار أو خطأ استيراد كشفًا محاسبيًا.

## الحدود

السجل الأول فقط يدعم هذه المصفوفة في CSV أو ورقة XLSX واحدة. الخريطة والسياسة وGL تبقى CSV القياسي. أسماء الحقول وعقد النطاق صريحة؛ لا تخمين لجدول عشوائي أو وراثة أبعاد من عنوان مدمج. جميع الدمج خارج هذه العائلة الأولى حتى يتوفر عقد هندسة أصلية مستقل. تبقى الصيغ أو إشارات عرض مالية غير قابلة للتحقق قيودًا ظاهرة.

حدود 8MiB للأصل و 100 عمود و 20,000 صف فيزيائي إجمالًا باقية. يضاف فحص مسبق 20,000 سجل منطقي محتمل بعد التفكيك مع صفوف المصادر الأخرى، قبل تخصيص السجلات والاقتباسات. هذا حد موارد وليس قياس أداء على الحجم الأقصى. لا يغلق PDF/OCR أو التقييم أو جسور الحركة أو عزل خطأ مصدر المخزون أو كثافة مالية ضخمة.

```sh
pnpm test:inventory-matrix
pnpm test:inventory-matrix:oracle
pnpm test:inventory-matrix:proof
pnpm test:inventory-matrix:mutations
pnpm build
pnpm test:inventory-matrix:browser
```
