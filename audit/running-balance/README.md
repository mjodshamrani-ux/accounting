# دليل عائلة الحركة والرصيد الجاري

هذه أصول اصطناعية عامة لا تحتوي بيانات عميل أو مورد حقيقي. الإصدار المحلي `0.4.42` مرشح ينتظر البوابات وCI والمراجعة النهائية قبل النشر. نجاح هذا corpus يثبت العقد المحدود داخل المصدر، ولا يثبت صلاحية ميدانية أو اكتمال مستندات خارجية أو اعتمادًا ماليًا.

## الأوراكل المجمد قبل الكود

المجلد `frozen/` نسخة حرفية من الحزمة التي راجعت مستقلًا قبل تنفيذ المنتج. يحتوي 44 حالة: `P01`–`P08` موجبة و`N01`–`N36` سلبية، و96 عضوًا مسجلًا تشمل PDF وحقائق JSON وCSV المتوقع للموجبات. لا ينتج المنتج هذه الحقائق أو يعيد كتابتها.

- بيان النسخ [INPUT-MANIFEST.json](frozen/INPUT-MANIFEST.json)، وبصمته SHA-256 هي `76a277fcee53c7448507244058e5760e269e78dd666d144b5b8d3ed6bac8b552`.
- [ACTION-TRUTHS.json](ACTION-TRUTHS.json) نسخة حرفية للأفعال A01–A24، وبصمتها `ba1fde2c912f99f0a72f8b1f5e1b25e4b6bd53eacfd8a94ba621e9062c784f68`.
- كل حالة موجبة تقارن جميع الصفوف والصفحات وسبعة حقول حرفية مع الحقيقة المؤلفة؛ تمر دورات الموجبات الثماني بالحفظ والاستعادة وExcel. الحالات السلبية تحجب الاشتقاق كله وتحتاج التشخيص المرتبط بسببها، ولو أبقت الصافي متساويًا.

## انحدار Unicode منفصل

المجلد `unicode/` أضيف كاختبار اصطناعي بعد التنفيذ وقبل رصد الناتج. ليس عضوًا في البيان المجمد ذي 44 حالة، ولا يعيد تعريف أوراكل سابق للكود. يحمل PDF نصيًا أصليًا ووصفًا `😀` وحقائق وCSV متوقعًا مؤلفًا استقلالًا عن المنتج. بصمة PDF هي `87293d91a460d571f8f0eb15899551c3e231e7a4e1fcd9f8afdb2a3e2f66056b`. يختبر مدى حرف UTF-16 بطول وحدتين وحفظه عبر الأثر وExcel.

## التشغيل والتقارير

من جذر المستودع، شغّل `pnpm test:running-balance` و`pnpm test:running-balance:proof` و`pnpm test:running-balance:mutations`. بعد `pnpm build` ومع وجود Chrome/Chromium، شغّل `pnpm test:running-balance:browser`. الأوامر تحفظ افتراضيًا في `work/running-balance-*`، ويمكن تحديد مواقعها صراحة عبر `RUNNING_SESSION_REPORT_DIR` و`RUNNING_REPORT_DIR` و`RUNNING_MUTATION_REPORT_DIR` و`RUNNING_BROWSER_REPORT_DIR`؛ يستخدم CI دليل المشغل المؤقت ولا يرفع تقارير الأصل أو التنزيلات.

سائق `scripts/running-balance-proof.mjs` يفحص جميع أعضاء البيان قبل قراءة المنتج، ثم ينتج 44 نتيجة مجمدة ونتيجة Unicode منفصلة، وتسع دورات موجبة. يفحص `scripts/check-running-balance-exports.py` الأثر وCSV وPDF ونصوص XLSX وأنواع خلاياه وخطوات الرصيد وعضويات الضوابط باستخدام Decimal وZIP/XML دون استيراد المنتج. يفحص أمر المتصفح مخرجات `ar/` و`en/` استقلالًا، مع 22 حالة و36 مصنفًا في corpus الحالي.

تفرض الاختبارات سقوف PDF/CSV و100 صفحة و20000 صف و32767 وحدة للخلية و4096 اقتراح و65536 وقوع دليل ومليون عقدة وعشرة ملايين وحدة نصية وعمق 14، مع الحد/+1 والخيارات المخفضة. لا تعني تلك السقوف وعد قبول كل تركيبة تحتها. ترفض نتيجة المصدر الصالح قبل التسليم إذا تجاوزت أدلتها المتكررة ميزانية الأثر. يظل القبول محليًا `financialApproval=false` و`scopeConfirmed=false`، ولا يعيّن الأثر opening/closing في مقارنة أخرى.

لحدود العائلة ودورة المراجعة: [P4-RUNNING-BALANCE.ar.md](../../docs/P4-RUNNING-BALANCE.ar.md).
