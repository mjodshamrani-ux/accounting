# INV-1F-G1 مصدر PDF الأصلي المحروس

هذه أول وحدة تنفيذية بعد [أساس PDF](../inventory-pdf-foundation/README.ar.md)، وليست تفعيل PDF ماليًا للمخزون. [العقد](contract.json) يحدد السقف، و[تقرير التنفيذ](../../docs/audits/INV1-PDF-NATIVE-SOURCE.ar.md) يسجل النتائج والقيود.

يفصل readNativePdfSource جمع النص المحروس عن إسقاط الأعمدة العام في readPdf. يشتركان في القارئ وحراس الخط والدفق والطلاء والظهور والصور والحدود. يحتفظ الناتج ببصمة البايتات الملتقطة والصفحات وحدود العرض وموضع كل جزء نصي غير فارغ ورقم عنصره الأصلي. يحتفظ بتحذيرات القراءة ولا يعطي اعتمادًا ماليًا. لا يوجد مدخل يقبل هندسة مخبأة من العميل بوصفها مصدرًا.

الأوامر: pnpm test:inventory-pdf:native-proof وpnpm test:inventory-pdf:native-mutations. الوحدات ضمن pnpm test ويمكن تشغيل tests/pdf-native-source.test.ts منفردًا.

يولّد المسبار أصول v2 المختومة دون تغييرها، ويقرأ ملفات PDF التسعة عشر بالقارئ الفعلي، ثم يرسل الهندسة إلى check_reading.py. يقرأ المدقق الأصل مستقلًا عبر أوراكل الأساس المجمد، ويطابق كل نص ظاهر وموضعه وحجمه وصفحته، ثم استشهادات الحقول والأبعاد والحدود والنطاق. قد تقسم PDF.js عبارة واحدة عند المسافة؛ يثبت المدقق كل حرف بموقعه الأصلي، ولا يسقط المسافات اعتباطيًا أو يضم عمودين. هذه قاعدة تحقق لشاهد Courier فقط، وليست خوارزمية قراءة مالية في المنتج.

الأدلة الناتجة خاصة داخل work أو مسار البيئة المحدد، ولا ترفع المصادر المولدة أو القراءات أو سجلات الجهاز. INV_PDF_NATIVE_PROOF_DIR وPDF_NATIVE_SOURCE_MUTATION_DIR يحددان وجهة التشغيل في CI. يبقى رفض stock-read الحالي محفوظًا حتى تنفذ المراحل المالية اللاحقة بأدلتها.
