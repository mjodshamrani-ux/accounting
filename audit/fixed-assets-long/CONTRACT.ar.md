# عقد تحضيري: سجل الأصول الطويل بالمكونات المقدمة

العائلة المقترحة `fixed-assets-long-components-gl-1` توسع مصدر السجل فقط داخل مجال الأصول القائم. أربعة أصول CSV مستقلة: register وmapping وpolicy-evidence وgl. لا تنفيذ منتج أو قبول ميداني في هذه الحزمة. أساس المعنى هو العقد المنشور `fixed-assets-posted-components-gl-1`؛ تبقى العائلة الأفقية وجلساتها وعلاقاتها كما هي.

كل أصل يسجل أربعة صفوف ذات Component صريح من القاموس المغلق `cost`, `depreciation`, `impairment`, `carrying`. هذه عائلة بنيوية لأن دليل اكتمال المكونات ووحدانيتها وعضوية الصفوف يتغير، وليس لتغيير ترتيب الأعمدة أو أسماء الملفات.

## النطاق والهوية

اثنا عشر حقل نطاق تتكرر حرفيًا في كل صف من الأصول الأربعة: Entity, Asset ledger, GL ledger, Currency, Currency basis, Posting status, Posting layer, As of, Chart version, Map version, Component policy version, Asset account set version. النطاق هو لقطة رصيد عند `asOf`، وليس فترة حركة أو roll-forward. لا افتتاح أو إضافة أو استبعاد أو تحويل عملات؛ `functional` و`posted` فقط، والتأكيد boolean true.

هوية الأصل داخل النطاق هي الزوج الحرفي `(Asset ID, Asset dimensions)`. مفتاح المكون `(scope, Asset ID, Asset dimensions, Component)`. لا تصبح Valuation reference جزءًا من الهوية يسمح بتكرار الأصل؛ يجب أن تكون واحدة متطابقة في الصفوف الأربعة. هوية الحساب `(GL account, GL dimensions)` داخل النطاق نفسه. يأتي الحساب من الخريطة المستقلة؛ لا يستنتج من اسم الأصل أو نوع المكون. `001` و`1` هويتان مختلفتان، وكذلك الأبعاد المختلفة للاسم نفسه. لا تقليم أو تطبيع أو تحويل رقمي للهوية.

## المصدر الطويل والعضوية

رؤوس register السبعة عشر: Asset ID, Asset dimensions, Component, Amount, Valuation reference، ثم رؤوس النطاق الاثنا عشر. يقبل تبديل ترتيب هذه الأعمدة مع فرادة كل رأس وحضور المجموعة كاملة، ولا يقبل مزيج الرأس الطويل والأفقي أو حقولًا إضافية. صف أول للعناوين، CSV UTF-8 صارم بفاصلة، مع قواعد الاقتباس الموروثة. كل صف بعد العنوان يحفظ موضعه وخلاياه؛ الصف الفارغ يحفظ في الجرد، وكل صف غير فارغ عضو في القرار ولو كان تالفًا.

يجب وجود كل مكون مرة واحدة بالضبط لكل أصل. الصفر المكتوب قيمة وعضو ودليل، لا فراغ. حذف المكون الصفري أو أي مكون، وتكراره بالقيمة نفسها أو بقيمة مختلفة، موانع `source-error` تجعل إجماليات القرار وقيم المقارنات null. لا تُنتقى أول نسخة ولا تجمع النسخ. يكتشف المنافس من الخلايا الخام حتى لو كان مبلغه تالفًا؛ لا يسقط صف متأخر لصناعة وحدانية. اختلاف Valuation reference داخل الرباعية أو تلوث النطاق مانع مصدر.

Amount غير سالب مقدم حرفيًا. بعد اكتمال الرباعية السليمة فقط، يتحقق `cost - depreciation - impairment = carrying >= 0` بوحدات صغرى صحيحة. لا يملأ carrying أو الصفر أو أي مكون مفقود. تخزن قراءة كل مكون مستقلًا؛ السجل المجمع المنطقي لا يختلق صفًا أصليًا أفقيًا أو هوية عضو بديلة.

## الخريطة والسياسة والأستاذ

مصادر mapping وpolicy-evidence وgl تبقى برؤوسها وعائلتها الحالية. لكل أصل/مكون من cost/depreciation/impairment خريطة واحدة ودليل مستقل صالح يطابق الأصل والأبعاد وValuation reference والحساب والأبعاد والنطاق. توجد الخريطة والحساب للمكون الصفري أيضًا. carrying ليس مكون ربط GL رابعًا، ولا يقبل داخل الخريطة أو دليل السياسة. الحساب الواحد لا يفسر بمكونات متعارضة؛ يجوز تجميع أصول مستقلة في حساب المكون الواحد.

التصنيف والإشارة: cost = fixed-asset-cost/debit-positive؛ depreciation = accumulated-depreciation/credit-positive؛ impairment = accumulated-impairment/credit-positive. Value basis = provided-posted-component. صلاحية السياسة تشمل asOf والطرفين. صافي GL للكلفة debit-credit، وللمكونين الآخرين credit-debit. يبقى الصافي السالب سالبًا ويظهر فرقه. تقارن كل قيمة على مستوى الحساب/الأبعاد/المكون؛ لا يخفي تساوي الصافي فرقين متقابلين ولا يغني مجموع الفرق صفرًا عن الفروق الفردية.

نقص رابط mapping/evidence/gl أو اليتيم يبقى `missing` وفق العقد الحالي؛ يمنع القبول. يمكن عرض المجاميع المقدمة كتشخيص فقط عند سلامة المصدر، ولا يحول ذلك النقص إلى اتساق. كل خطأ مصدر يجعل إجماليات القرار وقيم المقارنات null، حتى لو كانت مجموعة أخرى سليمة. ترتيب الحكم: source-error ثم missing ثم difference ثم needs-review ثم consistent-with-evidence بعد قبول بشري كامل فقط. لا يعد الصفر أو readiness إذن قبول.

## النص والمال والحدود

SAR بدقتين، JPY بصفر، KWD بثلاث. ASCII وأرقام عشرية بنقطة فقط، دون علامة أو آلاف أو أس أو مسافات أو كسور زائدة. حد كل قيمة بوحدتها الصغرى 10^14 شاملًا؛ الحدود الموروثة للمجاميع الجارية وصافي GL والسجل محفوظة. الفرق المشتق قد يبلغ 2×10^14 بين قيمة أصل موجبة وصافي GL سالب، ولا يقص أو يقلب. لا تعتمد binary float في الأوراكل.

الهوية/النطاق حتى 500 وحدة UTF-16، والمراجع/الأحداث حتى 2000 وفق العقد القائم، دون Cc/Cf أو بادئات الصيغ/الأخطاء؛ Valuation reference في السجل والسياسة حتى 500. تاريخ ميلادي حقيقي YYYY-MM-DD للسنوات 0001–9999. كل أصل حتى 8 MiB، مجموع 20000 صف بيانات فيزيائي عبر الأصول الأربعة شامل الفراغ، 100 عمود، 32767 وحدة UTF-16 للخلية. لكل أصل أربعة صفوف سجل؛ لا يقسم عداد الصفوف على أربعة لتجاوز السقف. الأحداث 1000، أعضاء الحدث 20000، مجموع الأعضاء 100000، والجلسة 64 MiB. XLSX مصدرًا خارج هذه الدفعة؛ لا يضاف بالتسمية دون عقد دقة وعلاقات أوراق وفحص مستقل.

## الدليل ودورة القرار المطلوبة لاحقًا

دليل القيمة: source role/index، SHA256 وبايتات الأصل، sheet=0، row/column الفيزيائيان، header/Component وAmount النصيان، هوية الأصل والأبعاد والنطاق وValuation reference، القيمة بوحدتها الصغرى. كل مكون يشير إلى خليته الأصلية وكل سجل مجمع يشير إلى أعضاء صفوفه الأربعة. تبقى كل خلايا الصفوف التالفة والفراغ والجرد متاحة. لا يحل computed أو cache محل الأصل.

اختيار العائلة صريح للسجل فقط؛ بقية الأدوار تبقى عائلتها الحالية. تدخل القراءة والعائلة والأصول الأربعة والنطاق ودليل اكتمال الحسابات في السياق. الاستبدال أو تغيير أي منها يبطل قبولًا أو نتيجة أو تنزيلًا قديمًا. القبول يطابق جميع الأعضاء غير الفارغين من المصادر الأربعة، يتطلب financial=ready وتصريح اكتمال موثقًا؛ الرفض/undo يحافظان على العضوية الكاملة. لا قبول جزئي لأصل سليم وسط مصدر تالف.

الحفظ والاستعادة والعامل والتصدير يلتقطون الأصول والبيانات الوصفية قبل أول await، يتحققون من hashes ويعيدون التحليل. التصدير يحتفظ بجداول المجال الحالية ويضيف دليل المكونات الطويلة وربط الأعضاء، دون الادعاء أن الصف المجمع صف أصل. يلزم مدقق CSV/Decimal/ZIP/XML مستقل يسترجع الأصول الأربعة والقيم ومواضعها والمقارنات. نسخة الجلسة/التصدير تفصل أثناء التنفيذ وفق الحاجة مع حفظ توافق القديمة؛ لا يقرر التحضير رفعها دون فحص المسارات.

## حدود الادعاء

العينات اصطناعية محددة قبل مشاهدة أي تنفيذ جديد. الأوراكل مستقل عن شفرة المنتج وعن نتائجه، والمراجعة المستقلة تعيد حساب الحقائق من البايتات. لا تنفيذ مالي جديد أو استهلاك أو انخفاض مشتق أو تقييم أو رأي اكتمال خارجي أو وجود/ملكية أصل أو قيود منشأة أو نتيجة ميدانية. المتصفح وCI والنشر خارج هذه المهمة.
