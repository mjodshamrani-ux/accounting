# تراصف 0.4.22 — حصر صفوف الصورة قبل الحسابات

أضاف الإصدار سجلًا اختياريًا يربط القصاصات المراجعة بصفوف جدول واحد، ويمنع خلط مبلغ الحركة بالرصيد المجاور، ويحفظ الإجماليات المستبعدة والصفوف غير المقروءة. تعديل القيمة أو السبب أو الحدود يلغي الموافقات ذات الصلة. الصور ما زالت خارج مصدر الحسابات، ولا تغيّر في قواعد المطابقة أو إصدار المحرك. [التنفيذ والدليل والحدود](P6-TABLE-INVENTORY.ar.md).

نجح محليًا 1066 اختبار وحدة وTypeScript والبناء وفحص الملفات المتأثرة. فحص Python مستقل سجلًا فعليًا من المتصفح. دورة المتصفح المحلية النهائية لم تكتمل بسبب قيود بدء Chromium بعد تغيير الصلاحيات؛ نجاحها ونشر الموقع مشروطان ببوابة GitHub. لا نعلن اكتمال النشر قبل ظهور نتيجتها.
