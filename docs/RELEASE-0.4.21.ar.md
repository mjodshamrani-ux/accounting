# تراصف 0.4.21 — مراجعة ما لم يقرأه OCR

أضافت الدفعة تحديد قيمة مباشرة من صورة PNG وإدخالها مع قصاصتها، وإبطال المراجعة عند التعديل، وحفظ سجل إصدار 2 واستعادته دون تعطيل السجلات السابقة. تبقى القيم أدلة مراجعة مستقلة عن الحسابات والمطابقة وExcel. [تفاصيل التنفيذ وقياس OCR وحدوده](P6-MANUAL-REGIONS.ar.md).

نجح محليًا 1,055 اختبارًا، وفحص TypeScript والمتصفح الأصلي بالعربية والإنجليزية والجوال، والفحص المستقل بـPython. كُشفت تسعة أعطال متعمدة لمسار P6؛ أربعة جديدة. لا نعلن نجاح كتالوج GitHub أو النشر الحي قبل اكتمالهما.

تجربة القراءة البديلة لم تحسن الأرقام العربية: أعلى نتيجة 2/13 ضمن الصورة المقاسة، مع إخفاق جميع المبالغ الـ11 ذات الأرقام العربية أو الفارسية. لذلك لم تتغير إعدادات القارئ ولم يتفعل مزود AI. المراجعة اليدوية لا تحول تلك النتائج إلى نجاح OCR، ولا يغلق هذا الإنجاز P6 كله.

حالة النشر: قيد بوابات GitHub والفحص الحي للالتزام النهائي.
