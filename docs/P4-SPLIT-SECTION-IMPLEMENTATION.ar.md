# P4: اشتقاق أقسام PDF بمدين ودائن منفصلين

هذا مرشح تنفيذ محلي للعائلة المحدودة `P4_SPLIT_SECTION_SAR2_V1`، مستقل عن عائلة المبلغ الموقع السابقة. لا يُدمج أو يُنشر قبل مراجعة Astra المستقلة للمرشح النهائي ونجاح بوابات المشروع وCI. نجاح الحالات الاصطناعية لا يمثل اعتماد عائلة ميدانية أو قياس جهد المحاسب.

## القراءة والمال

PDF نصي أصلي واحد، بأربعة فواصل أعمدة صريحة ثابتة في جميع الصفحات، ورأس حرفي `Date, Reference, Description, Debit, Credit`. تمهيد الصفحة `SYNTHETIC ONLY`، والتصريح الأول `Currency: SAR`، وقراءة معاملات SAR بدقة منزلتين ومنظور `debit-minus-credit` دون عكس إشارة. هذه عائلة العينات المقبولة؛ التمهيد الحر أو PDF عربي أو OCR أو FX أو أرصدة جارية خارجها.

يستخدم الحساب BigInt للوحدات الصغرى. كلا الجانبين مكتوب صراحة بصيغة ASCII غير سالبة ونقطة عشرية ومنزلتين كحد أقصى؛ الفراغ ليس صفرًا، ولا تقريب أو تحويل فواصل. لا يجوز جانبان موجبان في الحركة، ويجوز كلاهما صفرًا. حد كل مكون ومجموعه `10^14` شاملًا. يحتفظ CSV بالعمودين والنصوص الأصلية، ولا يحولهما إلى مبلغ موقع.

الأب `Invoice: ID` فريد في الملف. المرجع الصريح يطابقه، والمرجع الفارغ يحتاج اقتراحًا وأدلة خلايا الأب والمتابعة والرأس. بداية أب جديد أو الفاصل أو مجموع القسم تغلق الحدود السابقة. استمرار الصفحة يحتاج الصفحة التالية مباشرة ورأسًا مطابقًا وmarker مطابقًا. تحمل الخلايا هوية الأصل والاستخراج والمراجعة والورقة والصف والصفحة والعمود والنص والمدى الحرفي.

مجاميع القسم والصفحة والملف تتحقق بالمكونين منفصلين. المبلغ المرحل هو دوران القسم التراكمي؛ يلزم ردّه قبل الحركات التالية ولا يدخل في الحساب ثانية. كل صف يبقى في الجرد. الخطأ المتأخر يحجب الملف كاملًا، دون CSV جزئي أو سلطة مالية جديدة.

## دورة المراجعة والأثر

`inspect` يعيد الجرد والتشخيص والأدلة، ولا يصدر إيصالًا. يحتاج القبول اختيار جميع الحركات، بما فيها الصفر، وجميع اقتراحات المرجع اللازمة، واسم مراجع وسبب وسبعة إقرارات صريحة. الإيصال كائن مملوك للجلسة الحية أحادي الاستخدام؛ يستهلك قبل انتظار التطبيق حتى إذا فشل لاحقًا. تغير المصدر أو القراءة أو المراجع أو الاختيار أو جيل العملية يبطل السياق، ونسخة JSON لا تملك سلطة الإيصال.

تؤخذ نسخة مملوكة قبل أول انتظار. تغير مدخل المستدعي بعد اللقطة لا يغيرها، واستبدال مصدر الجلسة أثناء العملية يمنع نشر نتيجتها. يوجد جسر اختباري لبيانات هوية الصف؛ أي هوية غير التسلسل الأصلي `1..N` ترفض، ولا ترتب أو تصلح الخريطة. لا يغير هذا مخطط SourceFile العام.

الأثر الإصدار `P4_SPLIT_SECTION_ARTIFACT_V1` يحفظ أصل PDF منفصلًا وCSV الأصلي المشتق وقراءتهما وجرد الصفوف وروابط OriginalRow→DerivedRow وأدلة المدين والدائن والمجاميع وسياق المراجع وبصماته. `financialApproval=false` و`scopeConfirmed=false` ثابتان. إعادة التحقق والحفظ والاستعادة والتصدير تعيد قراءة الأصل وتثبت النصوص والعضوية والمبالغ. الإيصال المحفوظ تاريخ دليل فقط؛ الاستعادة لا تسجله في سجل ملكية الجلسة، ويحتاج التطبيق الجديد مراجعة جديدة.

تصدير XLSX يحفظ سبع أوراق: القراءة، الجرد، روابط الحركات، أدلة الخلايا، المجاميع، تاريخ المراجعة، وأصل PDF مرمزًا في قطع نصية. كل خلية نصية دون صيغة وبحد 32767 وحدة. أدلة الخلايا أعمدة مستقلة بدل وضع كائن JSON متكرر داخل خلية قد تتجاوز حد Excel. CSV لا يحمل نوع خلية ولا يضمن تفسير Excel الخارجي له.

## الموارد والإلغاء

حدود الأصل 8MiB و100 صفحة و20000 صف و32767 وحدة في الخلية؛ الاقتراحات 4096 ووقائع الأدلة 65536. يدقق plain data وdescriptors قبل النسخ، ويرفض getters والأنواع غير البسيطة. تبقى حدود القارئ الأصلي للنص وعدد عناصر PDF قائمة. تحتفظ القراءة العامة بحدها الافتراضي 4096؛ تمرر هذه العائلة حد 32767 الصريح الموجود في API، ويطبقه فرع PDF كما في CSV وXLSX.

هذه حدود قصوى متزامنة، وليست وعدًا بقبول كل ملف يقل عن أحدها. يحمي جرد plain data كذلك حد مليون عقدة وعشرة ملايين وحدة نصية إجمالية وعمق 14؛ تشمل وحدات النص مفاتيح الحقول ونسخ الأدلة المحفوظة. يُفحص الأثر المشتق بهذا الحد قبل تسليمه، فلا تظهر نتيجة ناجحة لا يمكن حفظها أو تصديرها بسبب حد بياناتها. يبقى حد CSV الكامل 8MiB مستقلًا عن حد الخلية. تثبت حالتا السعة الاصطناعيتان الإضافيتان حفظ CSV من 570 حركة يتجاوز 32767 وحدة، ورفض الأثر من 1800 حركة قبل تسليمه حين تتجاوز بياناته الإجمالية الحد؛ لا تغيّران الأوراكل المجمد للحالات الـ55 أو تمثلان دليلًا ميدانيًا.

حد `maxMoneyEvidenceCells` الإضافي يحسب دليلَي المال لكل حركة، بما فيها الصفر، مستقلًا عن حد جميع وقائع الأدلة؛ لا يعيد تعريف وحدة المورد. يبقى حد الاقتراحات مطالبة واحدة لكل مرجع حركة فارغ. لا ترفع الخيارات الحدود الافتراضية. الإلغاء قبل التشغيل يحدث قبل نسخ البيانات؛ ثم يفحص عند تقدم الصفحات وyield كل 256 صفًا فيزيائيًا وقبل النشر. لا وعد بمقاطعة hash أو getTextContent فورًا.

## مدخلات القبول وإعادة التنفيذ

ثُبتت الحالات الـ55 قبل استيراد المنتج. بصمة `audit/split-section/INPUT-MANIFEST.json` هي `ebb1f9678384fa35ff23c28d636c240c6d1488ac483006ae85a20b019e2bc16c`. ربطت حالات MAP الخمس بالأصل الهندسي المصحح وقصاته دون تغيير أخطاء خريطتها أو الأوراكل المالي. بقيت حزمة التحضير التاريخية ذات بصمة `e00a7fbf91b00a640293e0d03c94c01084a988cc3d85ea889411a861397290c4` مستقلة دون تعديل.

الأوامر المطلوبة:

- `python3 -B audit/split-section/verify_inputs.py` و`python3 -B audit/split-section/check_oracle.py` للتحقق المستقل من الأصل والصفحات والقيم والمجاميع وCSV.
- `pnpm test:split-section` لقراءة الحالات الأصلية، وجميع الموجبات والسلبيات، والأفعال الـ24 والملكية والإلغاء والحدود.
- باستخدام `P4_REPORT_DIR` خارج المصدر العام: تشغيل الاختبارات ثم `python3 -B scripts/check-split-section-exports.py "$P4_REPORT_DIR"` لفحص ZIP/XML/Decimal وأنواع الخلايا والنصوص والأصل دون استيراد حساب المنتج.
- `pnpm test:split-section:mutations` للطفرات الدلالية الموجهة؛ لا يعتبر خطأ بنية تحتية أو syntax قتلًا لطفرة.
- `pnpm test:split-section:browser` للواجهة الفعلية باستخدام Chrome والعربية والإنجليزية والمصادر والاختيار والإقرارات والإلغاء والتنزيل والاستعادة دون سلطة تلقائية.

يشمل CI هذه الخطوات، مع البوابات العامة والطفرات المحاسبية السابقة. تبقى قائمة المصدر والتوزيع المقترحة إعلانًا يحتاج المراجعة المستقلة، وليست موافقة نشر ذاتية. أدلة التشغيل المحلية الخام خارج قائمة المصدر العام.
