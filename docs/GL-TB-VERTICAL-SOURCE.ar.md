# مصدر ميزان المراجعة الرأسي

مرشح محلي 0.4.43 فوق الإصدار المنشور 0.4.42. العائلة `GL_TB_VERTICAL_BALANCES_V1` توسع قراءة ميزان حساب واحد داخل خدمة GL–TB القائمة. لا تزيد عدد العلاقات المحاسبية أو سلطة اعتماد النتائج.

## الأصل والمال

CSV أو XLSX أصلي؛ الرأس الأول يحتوي مرة واحدة على: `Snapshot ID, Balance role, Entity, Ledger, Account, Complete dimensions, Currency, Currency basis, Posting status, Posting layer, Period start, Period end, Debit, Credit`. ترتيب الأعمدة والصفوف قابل للتبديل. ثلاثة صفوف لازم وجودها صراحة: `opening`, `period`, `closing`، بمعرف لقطة واحد ونطاق كامل مكرر في كل صف. الصفر مكتوب؛ الفراغ لا يتحول إلى صفر. تكرار الدور أو معرف لقطة ثان أو حساب أو فترة أو عملة أو أبعاد أخرى يمنع الاعتماد.

كل دور يقدم المدين والدائن، ويجوز كونهما موجبين معًا. مصدر GL التفصيلي يحتفظ بعائلته الحالية. لا يُنشأ صف TB أفقي بديل عن الأصل الرأسي. تربط المكونات الستة بست خلايا من ثلاثة صفوف فعلية. جسر كل مصدر مستقل: الختام المدين ناقص الختام الدائن ناقص الافتتاح المدين زائد الافتتاح الدائن ناقص مدين الفترة زائد دائن الفترة. تقارن المكونات الستة منفصلة؛ تساوي الصافي لا يغلق فرق الدوران.

خطأ المصدر يسبق نقص الدور، ثم الجسر غير الصفري، ثم فرق المكونات، ثم الاتساق ضمن النطاق. لا استعارة أرصدة من GL ولا استنتاج فترة مفقودة. حدود المال والدقة والتواريخ والنطاق الحالية محفوظة. تعالج الأرقام العربية والفارسية وعلامات الاتجاه المالية المحددة مع حفظ النص الخام؛ لا تطوى هوية الحساب أو ترتيب أبعاده.

## المراجعة والجلسة والأدلة

يختار المراجع شكل الميزان صراحة ويؤكد الجدول والنطاق. تغيير الملف أو الورقة أو العائلة أو النطاق يلغي النتيجة والتنزيل السابق. تعرض الواجهة أدوار الميزان الثلاثة ومعرف اللقطة والصف وخليتي المال ومواضعهما. يبقى التصميم ضمن مساحة GL–TB الحالية بالعربية والإنجليزية.

يعيد الحفظ والاستعادة والتصدير قراءة البايتات الأصلية، وتبقى الجلسات الأفقية القديمة قابلة للاستعادة. النتائج وparsed cache المحفوظة ليست سلطة. ورقة Excel تحتفظ بالجرد الحرفي وبايتات المصدر وبصماته وعائلة القراءة والورقة ومعرف اللقطة ودور الرصيد، وروابط كل مكون إلى خلية مصدره. تكون النصوص المصدرة نصوصًا حرفية، بما فيها النص المشوه الذي أدى إلى رفض مالي.

حواجز XLSX للصيغ والدمج والخفاء والروابط والعرض غير الموثوق باقية. للعائلة الرأسية حارس إضافي يرفض التنسيق العددي الثابت الذي يخفي كسورًا موجودة في المبلغ، بما فيه تنسيق شرطي محتمل. حدود الملف والجلسة والصفوف والأعمدة والأوراق والخلايا لا ترتفع. إلغاء العمل ينهي العامل وتُرفض استجاباته المتأخرة؛ إعادة المحاولة تجهز عاملًا جديدًا.

## الحقيقة والفحوص

حزمة `tests/fixtures/gl-tb-vertical` تحتفظ بـ99 أصلًا وملف حقيقة اصطناعيًا مؤلفًا قبل التنفيذ، وختمها الأصلي `f97536a72b2d70ff5726c4ade85fcbb0aca5f1deb8d6e9b333c490e5baab0e59`. فيها30 حالة:9 متسقة، فرق واحد،2 غير متسقة،3 ناقصة،13 خطأ مصدر،2 مرفوضتا رأس. الضوابط الأفقية التسعة تثبت بقاء العائلة السابقة. ملفات العقد المحددة قبل التنفيذ في `tests/fixtures/gl-tb-vertical-contract`؛ لا تعدل للحصول على نجاح الاختبار.

الفاحص المستقل يعيد أموال CSV وXLSX الأصلية بأعداد صحيحة ودقة Decimal، ويفحص تنزيلات Excel وعضوية الخلايا والجسرين والفروق. لا يستورد حساب المنتج ولا يستخدم المال المعروض في التصدير حقيقةً متوقعة. الاختبارات العدائية والطفرات تمنع إسقاط فترة صفرية، وفوز أول دور مكرر، وتبادل الجانبين، والاعتماد على الصافي، واستعارة GL، وربط الجميع بصف افتراضي، وإغفال العائلة من السياق أو خطأ متأخر أو عرض كسور مضلل.

الأوامر: `pnpm test:gl-tb-vertical`، `pnpm test:gl-tb-vertical:proof`، `pnpm test:gl-tb-vertical:mutations`، `pnpm test:gl-tb-vertical:browser`. تبقى بوابات المشروع السابقة مطلوبة. تقارير التشغيل محلية في مجلدات مهملة من Git أو مسارات تقرير خارج المصدر؛ لا يرفع أي دليل تشغيل ضمن ملفات المنتج.

## حدود القبول

هذه عائلة بنيوية واحدة؛ اختلاف CSV/XLSX أو اللغة أو دقة العملة ليس عائلة أخرى. لا تحقق ميداني أو قياس جهد محاسب أو إثبات لاكتمال ERP أو عدالة القوائم. لا GL متعدد الحسابات ولا FX أو توليد دوران من صافي أو إعادة تصنيف أو اعتماد مالي. المرشح المحلي يحتاج مراجعة شجرته النهائية قبل أي دفع أو PR أو دمج أو نشر.
