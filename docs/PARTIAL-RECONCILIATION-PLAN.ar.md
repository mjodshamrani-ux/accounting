## قاعدة التنفيذ

القبول والقراءة والمطابقة واكتمال التسوية قرارات مختلفة. يمكن قبول الملف وإخراج ورقة عمل جزئية مفيدة مع وجود صفوف غير صالحة. لا يتحول الصف الخاطئ إلى مبلغ صفري أو تاريخ مفترض، ولا يختفي من سجل المصدر، ولا يصبح استبعاده شرطًا للوصول إلى النتائج.

| المشكلة | السلوك المطلوب |
|---|---|
| مبلغ أو تاريخ غير صالح في صف ذي هوية مقروءة، ولا يتصل بحركات أخرى | الاحتفاظ بالصف والخطأ، ومطابقة المكونات المستقلة التي استوفت قواعد الإثبات |
| صف غير صالح يشترك في مرجع مستند أو دفعة أو دليل متداخل | إبقاء المكوّن المتأثر للمراجعة، بما فيه العلاقات غير المباشرة؛ متابعة المكونات المستقلة |
| هوية الصف الخاطئ فارغة أو غير موثوقة | إظهار الحركات المقروءة والمرشحين والأخطاء؛ لا نفترض تفرد هوية قد يكون هذا الصف تكرارًا لها |
| خلية غير قابلة للقراءة بأي صيغة مدعومة | لا تستخدم لإثبات صيغة المبالغ أو التواريخ؛ تبقى خطأً مستقلًا |
| قيم صحيحة لكنها تستلزم صيغًا متعارضة | لا نحذف القيم المخالفة لاصطناع صيغة واحدة؛ يوضح التعارض قبل الاعتماد |
| صيغة لها تفسيران ماليان مختلفان | يبقى اختيار المحاسب مرتبطًا بالمصدر وإعدادات القراءة؛ لا يُستبدل بتخمين |
| رصيد افتتاحي أو ختامي غير صالح | لا تعلن تسوية الرصيد؛ لا تجعل مشكلة الرصيد وحدها دليلًا على فساد هوية حركات مستقلة |
| تعارض في الحساب أو العملة أو معنى التقرير | لا يلتف عليه قبول الصفوف؛ نطاق المقارنة نفسه يحتاج التصحيح |
| صفحة PDF لم تُقرأ أو ملف تالف لا يمكن حصر محتواه | رفض القراءة الناقصة بوضوح مع سببها؛ لا يقدّم الجزء المتاح بوصفه المصدر الكامل |

## كيف يُعزل الخطأ

تُقرأ أدلة هوية الصف قبل محاولة حساب مبلغه أو تاريخه. لا تُستعمل هوية مستخرجة من صف مختل البنية أو من خلية أو عنوان مرجعي غير موثوق. انزياح عناوين الأعمدة أو وجود قيمة تشبه مرجعًا في موضع المبلغ أو التاريخ يمنع اعتبار الخطأ معزولًا؛ لا تكفي استقامة بقية الصف. تبقى جميع أدوار المراجع المؤثرة في الربط والتنافس ضمن الفحص، وتنتقل علامة التأثر عبر العلاقات المشتركة؛ لا يكفي اختلاف المرجع الرئيسي إذا كان هناك إيصال أو مرجع بنكي يجمع الحركات.

يشمل فحص نطاق المورد والحساب والعملة الصفوف التي فشل مبلغها أيضًا؛ لا يمكن إخفاء صف تابع لجهة أخرى بمجرد وجود خطأ فيه. هذه الأدلة السلبية تمنع الاعتماد المتأثر، ولا تثبت مطابقة ولا تعوض قيمة ناقصة.

## النتيجة التي يراها المحاسب

لا نضيف مربع «السماح بالأخطاء». ينتقل المحاسب إلى النتائج متى أمكن تفسير البيانات اللازمة. تظهر عبارة «نتيجة جزئية» مع عدد الصفوف المتأثرة، وقائمة يمكن الوصول منها إلى كل صف ومصدره وسبب الخطأ وقيمه الأصلية. إجماليات هذه النتيجة تخص الحركات المقروءة، ولا تُسمى أرصدة كاملة للمصدر.

تحتفظ ورقة Excel بالتفاصيل نفسها، بما فيها صفحة أخطاء القراءة والبيانات الأصلية. يبقى الوصف الجزئي بعد توقيع المراجعة. يعيد حفظ الجلسة واستعادتها وتصديرها قراءة الأصل والتحقق منه؛ لا يعتمد على حكم جزئي قديم. يشرح المساعد ما ثبت وما لم يثبت من النتيجة، ولا يملأ الخانات غير المقروءة بأرقام محتملة.

## بوابة القبول

نختبر إنجاز الأزواج والمجموعات السليمة المطلوبة بجوار صفوف خاطئة، وليس مجرد توقف آمن. ونختبر منافسًا في آخر الملف، ومرجعًا ثانويًا متداخلًا، وهوية مفقودة، وخطأ في كل طرف، وصيغًا متعارضة، وخلية Excel ذات قيمة غير موثوقة، ومنع تسوية الرصيد عند غياب حركة مقروءة.

تُكتب التوقعات قبل تشغيل المرشح، ويُحفظ أداء 0.4.12 مقابلها. تظل الإخفاقات السابقة مسجلة. تشمل دورة القبول الواجهة العربية والإنجليزية، والمراجعة والحفظ والاستعادة وExcel وفحصه المستقل، واختبارات تتعمد حذف الخطأ أو تجاهل أثره أو اعتماد المجموعة المتأثرة.

تستمر خطة الأحجام الكبيرة بعدها: القياس حتى 50 ألف ثم 100 ألف حركة، ومسار البنك بعقد منفصل لأصل الحوالة ورسومها. لا نرفع السعة أو نضيف نوع تسوية لتجاوز ضعف في عزل الأخطاء أو إثبات المطابقة.
