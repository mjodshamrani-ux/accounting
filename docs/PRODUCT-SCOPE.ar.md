# نطاق المنتج وحدوده

الهوية ودور العمود والعملة والإشارة والعضوية وأدلة المصدر شروط للقرار. الصفوف المتنافسة أو الأخطاء غير المحسومة تبقى للمراجعة. لا ينشئ المحرك قيدًا موازنًا أو رسمًا أو مخصصًا أو دليلًا لسد الفرق.

الموردون والعملاء يقارنون حركات ضمن قوالب محددة. المقاصة تحتاج مرجعًا كاملًا ونطاق حساب وعملة وفترة. تخصيص الدفعات يحفظ المتاح والمخصص والمتبقي ويمنع التجاوز وإعادة الاستخدام. البنك يفصل حركة المصدر وجسر الأرصدة وبنود التسوية وأدلة الافتتاح والختام. GL/TB وTB/القوائم يفحصان مكونات وأبعادًا وسياسة إشارات وخريطة مقدمة دون شهادة عدالة للقوائم.

الشركات الشقيقة وبوابات الدفع والدفاتر المتخصصة تحتاج الأصول والمكونات والعضوية الفيزيائية المبينة في عقد كل مجال. المخزون لا يحسب تقييمًا مفترضًا؛ الأصول لا تفترض عمرًا أو استهلاكًا؛ الرواتب لا تختلق تسوية بنك أو GL ناقصة. يحفظ كل مسار المراجعة والإلغاء والجلسة وأثر المصدر في التصدير.

حدود الاستيراد العامة: 8 MB للملف و100 عمود ونحو 20,000 صف و40 ورقة ومليون خلية للمصنف. CSV بترميز UTF-8 وفواصل محددة. XLSX المشفر والماكرو والروابط الخارجية مرفوضة. الأعمدة المختارة تحتاج قيمًا موثوقة؛ لا تُنفذ نصوص المصدر كصيغ.

PDF النصي محدود إلى 100 صفحة و8 MB و20,000 صف ومئة ألف عنصر نصي ومليوني حرف مع تطبيق جميع السقوف. القراءة المرئية التجريبية ليست مصدرًا ماليًا معتمدًا. المسار اليدوي لصورة PNG واحدة وجدول واحد محدود إلى 200 صف و2 MB، ويحتاج جردًا وعناوين وعملة وإجماليات وأدلة خلايا مربوطة بالمراجعة وإعادة تحقق عند النقل والاستعادة والتصدير.

المساعد يشرح حقائق المحرك بأدلتها. اقتراح النموذج لا يمنح صلاحية مطابقة أو اعتماد أو توليد أرقام مالية. المزود الدلالي التجريبي غير مفعّل في المنتج؛ نتائج التجارب المسجلة لا تثبت فائدة إضافية أو فهمًا عامًا. لا تنزل هذه الدفعة نموذجًا جديدًا ولا تدعي تشغيل استدلال جديد.

هذه حدود تطوير واختبار اصطناعي وليست اعتمادًا محاسبيًا أو تحققًا ميدانيًا مستقلًا. إعادة فتح الموقع دون اتصال غير مدعومة؛ يمكن متابعة العمل المحلي بعد تحميل البرنامج وفق قيوده.
