# إصلاحات أدوات التحقق ونص التصدير

دفعة تطوير محلي مستقلة عن مرشح النشر المجمد. تشمل نص Excel وأدوات الطفرات المتخصصة ومدخل قياس الأداء، دون تعديل خوارزمية المطابقة أو إضافة مصادر أو تبعيات أو تشغيل نموذج. المراجعة المستقلة والنشر مرحلتان منفصلتان؛ النجاح المحلي لا يثبت نجاح CI البعيد.

تتحقق صادرات AR والمقاصة والبنك وGL→TB من Unicode ومحارف XML وحد الخلية. ترفض النص غير القابل للتمثيل، وتحفظ CR وDEL والنص الحرفي الشبيه بتسلسلات OOXML باستخدام ترميز المعيار عند الكتابة. تبقى الجلسات والأموال والقرارات والعضوية كما هي. توسع الحارس إلى المسارات الثلاثة بعد إعادة إنتاج حذف DEL من أسماء مصادرها. يقارن قارئ Python مستقل النص الكامل، وتبقى أوراكل الأموال والمصادر الأصلية مستقلة عن مخرجات المنتج.

تشغل طفرات المخزون التسع والأصول الإحدى عشرة والرواتب الست عشرة في نسخ مؤقتة، وتسجل أحداث Node المهيكلة. لا يعد تعطل البيئة أو الاستيراد أو المهلة أو الإشارة قتلًا، وترفض رموز الخطأ غير المعروفة أيضًا؛ يلزم assertion مكتمل في اختبار الحاجز المقصود. يفشل baseline غير السليم قبل تشغيل الطفرات. يحتفظ child واحد جديد لكل تجربة بعزل المصدر، وتقرأ أحداث الاختبار داخله بتسلسل واحد لتجنب فقد رموز الأخطاء المتداخلة عبر IPC في Node. يثبت regression أن ENOENT وأخطاء الاستيراد والمهلة المتداخلة داخل assertion لا تعد قتلًا. يثبت اختبار انقطاع child أن المصدر الأصلي لم يتغير. أصبحت هذه بوابة مستقلة في CI وتبعية للنشر، وأضيفت إلى `pnpm check`.

العدد التاريخي 36 لا ينتقل تلقائيًا إلى المصنف الجديد. أعطى التقييم الصارم الأول 29/36؛ ست حالات انتهت بأخطاء غير assertion، وحالة استهدفت اختبارًا غير كافٍ مع وجود تغطية IO قائمة. صيغ عقد نجاح لقطة IO صراحة بـ`assert.doesNotReject` مع الاحتفاظ بالأخطاء البيئية الداخلية، وربطت الحالة الأخيرة بالاختبار الموجود الصحيح. أجازت إعادة الحساب المحلية الأولية 36/36، ثم كشف فحص الأخطاء المتداخلة فقد رموزها عبر IPC. صحح مسار الأحداث وأضاف regression يمر عبر الأداة الفعلية؛ أعيد حساب 36/36 بالمسار المصحح مع baseline وrestored سليمين. أدلة المحاولات السابقة محفوظة خارج المصدر ولا تثبت سلامة المصنف السابق. يجب إعادة البوابات على الالتزام النهائي، ولا تصح إعادة تسمية المحاولة القديمة.

يشير `test:browser:performance` و`test:reliability:performance` إلى المدخل الموجود نفسه. يحضر مصادر اصطناعية خارج checkout ثم يشغل المتصفح والمدققات المستقلة، مثل:

```
pnpm test:reliability:performance --sizes=1000 --formats=csv,xlsx --output=../local-performance-evidence
pnpm test:mutation-runner
SPECIALIZED_FAULT_OUTPUT_DIR=../local-fault-evidence pnpm test:specialized-faults
```

قياس الذاكرة هو مجموع RSS المرصود لعمليات Chromium، وقد يعد صفحات مشتركة مرتين؛ ليس JS heap أو قمة مضمونة. العينة الناقصة أو RSS الصفري تفشل؛ لا يحتسب الصفر كذاكرة صالحة. تحفظ هوية PID ومحاولة القياس وإثبات الغياب من CDP وفحص نظام التشغيل قبل أي محاولة جديدة. يسمح بمحاولة جديدة واحدة فقط عند ثبوت انتهاء عملية مساعدة من CDP ونظام التشغيل؛ فقد browser أو renderer أو worker أو GPU، أو فشل القياس المستمر، يبقى فشلًا. تحفظ المحاولات كلها، ولا تضاف نتائج متأخرة بعد انتهاء المهلة. يلزم وجود عينة كاملة داخل فترة تصدير Worker فعلية؛ تنزيل صحيح دونها لا يجتاز benchmark. لا تؤخر المحاسبة اصطناعيًا لزيادة عدد العينات.

يبقى الجهاز الضعيف الحقيقي والتقييم الميداني وجهد المراجع والمستخدمون المستقلون خارج هذه الأدلة المحلية. تحفظ الإخفاقات بأحجامها وأسبابها. لا تحول المصادر الاصطناعية أو نجاح جهاز واحد إلى دقة ميدانية أو SLA.

## إغلاق ملاحظتي المراجعة R1/R2

حماية underscore فقط عند بداية تسلسل OOXML تحفظ الأنماط التي تتشارك نهايتها وبدايتها (`_x005F_x0041_`)، والمتجاورة والمتكررة، دون فك متكرر أو استبدال خاص بعينة. قارئ ZIP/XML مستقل يطابق الملاحظة في AR بعد save/restore والتصدير المباشر، ويطابق أسماء المصدر في المقاصة والبنك وGL/TB؛ علامات الصيغ تبقى نصوصًا ولا تصبح عقد صيغ.

مصنف الطفرات يفشل مغلقًا لأي سبب غير مصنف، بما فيه Error أو TimeoutError بلا code داخل assertion. التقرير المهيكل الإصدار4 يتحقق من هوية الخطأ الأصلية وAssertionError الفعلية، ويربط حواف cause/actual/AggregateError بهويتها الأم وعدد الحواف المطلوب. وجود code وحده لا يمنح قتلًا. cycle أو تجاوز16 مستوى أو64 عقدة أو سبب غير Error يفشل اكتمال الرسم ولا يسقط بصمت. تبقى assertion المالية الصحيحة مقبولة ولو وردت كلمات تحميل/مهلة في رسالة التشخيص أو غلفتها assertion أخرى.

عند حدود assertions الخاصة بالرمي والرفض، تحفظ actual حتى لو كانت string أوobject أوnull أوundefined أونوعًا آخر؛ تسجل علامة محدودة آمنة بدل استدعاء getters أوtoJSON للكائن المجهول. الفرق بين غياب cause ووجود cause بقيمةundefined محفوظ. الرسم غير المكتمل أو الحافة المفقودة أو السبب غير الأصلي لا يجيز قتلًا. لا تعد actual الرقمية أوالكائنية في المقارنات المالية العادية سبب خطأ؛ ضوابط مالية موجبة تثبت ذلك. يتحقق قارئ الأحداث من أعداد الحواف حتى لو ادعى سجل ناقص اكتماله، وتختبر الحدود والتغليف المتداخل والأسباب الدائرية والأخطاء منrealm آخر. لا يستخدم المصنف كلمات رسالة التحميل أوالمهلة لتقرير القتل.

يحمّل الطفل المؤقت مراقب حدود الاستثناء قبل وحدات الاختبار. يسجل عودة callback أو رميه، وتسوية Promise الأصلية أو رفضها، ويحفظ الملاحظة في WeakMap داخل العملية لا في حقول يستطيع الخطأ إضافتها. غياب الاستثناء المتوقع عند throws أوrejects مقبول فقط بدليل عودة طبيعية أوfulfillment مع actual بقيمةundefined؛ رفض undefined الفعلي يبقى سببًا مجهولًا. لا استنتاج من رسالة “Missing expected”. لا يعاد استدعاء callback ولا تستبدل Promise الداخلة أوهوية سبب الرمي. Promise ذات hooks مخصصة أوsubclass أوrealm آخر لا تثبت غياب الاستثناء. تمرر Promise الخروج الفشل مجددًا بنفس الخطأ، حتى يبقى تجاهل assertion دونawait رفضًا غير معالج. تقبل حاوية Node من نوعtestCodeFailure فقط؛unhandledRejection وuncaughtException وأخطاءhooks لا تمنح قتلًا.

إذا رمى validator assertion أخرى، تبقى نتيجة الحد الخارجي وسبب الرمي محفوظين في حواف boundary، حتى لو اختلف operator. لا تمحو ملاحظة غياب استثناء داخلي رفضًا خارجيًا مجهولًا. المصدر الذي يساوي AssertionError نفسها يسجل كمرور للخطأ المعروف لا كدورة cause، بينما الأسباب غير المعروفة والملاحظات الناقصة والدورات الفعلية تبقى مرفوضة. يختبر الحارس هذا المسار قبل الإصلاح وبعده مع undefined وnull ونص وكائن وError تحميل عادية، إلى جانب الحدود السابقة.

أخطاء النطاق المقبولة السبعة معلنة لكل طفرة واختبار، بهوية Error الأصلية ورسالة كاملة مطابقة ومنشأ الرمي (ملف ودالة) وoperator assertion المحدد؛ يلزم أن تكون ورقة actual بلا أي سبب داخلي. هذه عقود لخرق اللقطة والتقويم المثبت، وليست سماحًا عامًا برسائل متشابهة. الخطأ المجهول أو من منشأ آخر أو له cause إضافي يظل Infrastructure. أسماء الطفرات وneedles/replacements الأصلية ثابتة. لا تغيير للمحركات المالية أو اعتماد مطابقة جديدة، ولا تثبيت تبعيات أو إعادة تشغيل نموذج.
