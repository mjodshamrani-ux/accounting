# إعداد الإصدار 0.4.43

يربط هذا الإصدار نتيجة اتساق الأستاذ وميزان المراجعة بمصادر الطلب الأصلية، ويربط الاستعادة بملف الجلسة المطلوب. يرفض العميل اختلاف النطاق أو القراءات أو هوية الملفات أو بايتاتها أو النتيجة، وينهي العامل ثم يسمح بإعادة محاولة نظيفة. يلتقط الطلب تزامنيًا قبل العمل غير المتزامن.

الوصول المثبت إلى الرد المخالف هو حقن داخلي مضبوط في الاختبارات، لا حادثة مستخدم أو استغلال خارجي مثبت. لم تتغير السياسة المحاسبية أو إصدار المحرك أو تنسيق الجلسة، ولم تُضم عائلات المصادر الإضافية من فرع التكامل.

أُعد المرشح من إصلاح محلي مستقل فوق main المنشور 0.4.42. تظل اختبارات المشروع والطفرات والفاحصات المستقلة والمتصفح وحراسة المصدر العام إلزامية. تُراجع شجرة الإصدار قبل رفعها، ويُشترط نجاح CI قبل الدمج، ثم نجاح نشر Pages وفحص الموقع الحي. هذه الوثيقة تصف إعداد الإصدار ولا تدعي نجاح بوابة لم تنفذ؛ تُحفظ معرفات التشغيل ونتائج النشر في سجل التسليم الخاص.
