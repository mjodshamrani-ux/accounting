# سجل أنماط التسويات

- **ما يسجله:** المشكلات، لا الأشخاص ولا الجهات.
- **كيف يُحدَّث:** بعد كل مقابلة، وفق [بروتوكول التحقق الميداني](FIELD-DISCOVERY-PROTOCOL.ar.md).
- **مستويات الدليل:** معرّفة في القسم 8 من البروتوكول.
- **حد التعميم:** لا يصبح نمط عامًا من مقابلة واحدة.
- **كلمة Supported:** لا تُستعمل هنا لوصف المنتج.

## صيغة القيد

| الحقل | المحتوى |
| --- | --- |
| **المعرّف والعنوان** | `PATTERN-NNN — وصف بجملة واحدة` |
| **الوصف** | المشكلة بصيغة عامة، ومثال مصطنع للبنية |
| **القطاعات** | وصف عام، بلا أسماء |
| **عدد المقابلات** | المستقلة فقط، مع معرّفات `OBS-V1-___` |
| **مستوى الدليل** | Observed once / Repeated / Structurally confirmed / Technically modeled / Field validated |
| **مصدر الدليل** | ما يحسم العلاقة (مرجع، أو إشعار، أو تأكيد، أو خبرة…) |
| **المعلومات داخل الملف؟** | نعم / أحيانًا / لا / غير معروف |
| **نوع العلاقة** | مطابقة (match) / تجميع متقابل (clearing) / مطابقة ملخص (summary tie-out) / تخصيص (allocation) / غير معروف |
| **ما قد يقدمه تراصف** | عنصر من التجارب، أو «تحديد وتسجيل» دون أتمتة |
| **ما لا نعرفه** | |

## الأنماط الميدانية

### PATTERN-001 — العملية نفسها تُمثَّل بحركات مختلفة بين نظامين

| الحقل | المحتوى |
| --- | --- |
| **الوصف** | الحدث الاقتصادي نفسه يظهر في نظام الجهة الأخرى بتمثيل يختلف عن تمثيله في دفتر الشركة: عدد الحركات، أو تقسيمها، أو طريقة تجميعها. مثال مصطنع للبنية: ما يظهر عند طرف حركةً واحدة بـ1,000، قد يظهر عند الآخر عدة حركات مجموعها 1,000 |
| **القطاعات** | وساطة التأمين |
| **عدد المقابلات** | 1. المصدر ملخص مقابلة نقله فريق المنتج في موجز التخطيط، ولا محضر محفوظ في المستودع |
| **مستوى الدليل** | **Observed once** |
| **مصدر الدليل** | غير موثق. بعض الحالات يحسمها نمط متكرر في تقرير الجهة (PATTERN-003)، وبعضها توضيح خارجي (PATTERN-002) |
| **المعلومات داخل الملف؟** | أحيانًا، بحسب الملخص |
| **نوع العلاقة** | غير معروف: مطابقة بتجميع (1:N أو N:1)، أو تخصيص. لا نعرف هل يُوزَّع مبلغ أم يُجمع صف كامل |
| **ما قد يقدمه تراصف** | مسار الموردين يجمّع حزمة المرجع كاملة حين يوجد مرجع مشترك قوي. دون مرجع: تحديد الحالة وتسجيل القرار البشري |
| **ما لا نعرفه** | أي عمود يربط الحركات، إن وُجد؛ هل التقسيم ثابت لكل جهة؛ هل يتكرر في قطاعات أخرى؛ حجمه ونسبته من الحالات |

### PATTERN-002 — علاقة التجميع قد لا تُحسم إلا بتوضيح من الطرف الآخر

| الحقل | المحتوى |
| --- | --- |
| **الوصف** | حين تُجمع عدة حركات مقابل عنصر واحد، قد لا يكفي الملفان لمعرفة أي الحركات تنتمي للمجموعة، فيُطلب توضيح من الطرف الآخر. مثال مصطنع: عدة مجموعات من الحركات مجموع كلٍّ منها 1,000، والتوضيح يحدد أيها المقصودة |
| **القطاعات** | وساطة التأمين |
| **عدد المقابلات** | 1، من الملخص نفسه |
| **مستوى الدليل** | **Observed once** |
| **مصدر الدليل** | توضيح خارجي، لا نعرف شكله: اتصال، أم إيميل، أم مستند |
| **المعلومات داخل الملف؟** | لا، في هذه الحالات |
| **نوع العلاقة** | غير معروف: مطابقة بتجميع أو تخصيص |
| **ما قد يقدمه تراصف** | تحديد الحالة وإظهار أن الحسم يحتاج معلومة خارجية، وتسجيل القرار بأساسه (النوع، والمرجع، والسبب). احتاجت تجربتا الحساب الوسيط والتخصيص هذا الشكل من الأساس، ولا يحمله القرار الإنتاجي الحالي |
| **ما لا نعرفه** | شكل التوضيح؛ هل يُحفظ ويقبله المراجع؛ كم تتكرر الحالة؛ هل يتحول التوضيح مع الوقت إلى قاعدة (PATTERN-003) |

### PATTERN-003 — بعض العلاقات تُعرف من نمط متكرر في تقرير الجهة

| الحقل | المحتوى |
| --- | --- |
| **الوصف** | يتعلم المحاسب نمطًا ثابتًا في تقرير جهة معينة، مثل مكان رقم أو معنى كود أو طريقة تقسيم، فيحسم به العلاقة في كل دورة دون سؤال |
| **القطاعات** | وساطة التأمين |
| **عدد المقابلات** | 1، من الملخص نفسه |
| **مستوى الدليل** | **Observed once** |
| **مصدر الدليل** | خبرة المحاسب بتقرير الجهة، وهي معرفة لا نعرف هل هي مكتوبة |
| **المعلومات داخل الملف؟** | نعم، لمن يعرف النمط |
| **نوع العلاقة** | غير معروف |
| **ما قد يقدمه تراصف** | قاعدة تفسير مسجلة لنطاق محدد (جهة وتقرير)، باعتماد صريح. لم يُختبر هذا في أي تجربة، ولا ينبغي أن يتحول قرار حالة واحدة إلى قاعدة تلقائيًا |
| **ما لا نعرفه** | ما الذي يُتعلَّم تحديدًا؛ هل يتغير النمط؛ من يعتمده؛ هل يتكرر لدى جهات أخرى |

## فرضيات من التجارب (بلا دليل ميداني)

| H-02 | موازين المراجعة تترك الأصفار فارغة، وحارس الصيغ الحالي يرفضها | GL/TB `dba761c` | شكل الميزان الحقيقي |
| H-03 | تقرير الأستاذ العام يحمل عدة حسابات، والقارئ الحالي يحمل حسابًا واحدًا في كل مصدر | GL/TB `dba761c` | عدد الحسابات في ملف الأستاذ المعتاد |
| H-04 | تساوي الصافي يخفي فرقًا في المدين والدائن | GL/TB `dba761c` | هل يوفر الميزان المدين والدائن منفصلين |
