# سجل الاكتشاف — فارغ عمدًا

لا توجد مقابلات أو حالات ميدانية مُنجزة مسجلة. المثال المدمج والاختبارات ليست بديلًا عن الاكتشاف.

السقف المقترح: 24 ساعة خلال أسبوعين، 8 محاسبين، 20 حالة، دون شراء أدوات/إعلانات. يُسجل الواقع الفعلي عند بدء الوصول للمستخدمين.

## نموذج الحالة

- معرف غير كاشف للهوية:
- الدور والبيئة:
- مصدر المعلومة: ملاحظة / قياس / تصريح / تقدير:
- تكرار المهمة والزمن الكامل:
- نوع وصيغة وحجم كشف المورد:
- نوع وصيغة وحجم تقرير AP:
- المورد/الجهة/الحساب/العملة/تاريخ القطع متوافقون؟
- أرصدة وتغطية متاحة؟
- معلومات خارج الملفين؟
- خطوات العمل وأطول أجزائه:
- المخرج المقبول ومعيار صحته:
- أهلية الحالة محاسبيًا قبل تشغيل المنتج:
- تدخل المؤسس:
- المشتري وصاحب صلاحية الاستخدام:
- دليل دفع أو التزام فعلي:
- نتيجة التجربة وإصدار المحرك:

القرار بعد السقف: Build / Change Scope / Stop. لا تُحذف إخفاقات إصدار سابق بعد إصلاحها.
