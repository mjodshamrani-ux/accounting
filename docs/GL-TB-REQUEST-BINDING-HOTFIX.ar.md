# مرشح إصلاح محلي لربط طلب GL–TB

هذا إصلاح محدود فوق مصدر الإصدار0.4.42، أُعد بهوية الواجهة0.4.43 للتمييز بين النسخة المصححة والأساس. رقم الإصدار ليس إثبات نشر؛ يلزم نجاح CI والمراجعة المستقلة قبل الدمج، ثم نجاح GitHub Pages والفحص الحي. لا يضيف TB الرأسي أو سحب/إيداع البنك أو سجل الأصول الطويل.

أعادت حاضنة مستقلة تحريف رد العامل بعد تنفيذ الشفرة الأصلية: أوراق مقروءة ونتيجة متماسكة لا تطابق أصول الطلب، وجلسة صالحة لحساب آخر لا تطابق جلسة الاستعادة المطلوبة. قُبل الردان على الأساس. الوصول المثبت هو حقن رد داخلي في حاضنة اختبار؛ لم يثبت حدوثه من الواجهة العادية أو سباق طبيعي أو استغلال خارجي أو تلف ملف مستخدم.

يلتقط العميل طلباتGL–TB تزامنيًا، ويعيد قراءة أصول طلب المقارنة أو جلسة الاستعادة المطلوبة، ثم يقارن النتيجة والنطاق والقراءات وهوية الملفات وبايتاتها. يثبت الحالة المعاد قراءتها فقط. يؤدي الاختلاف إلى رفض الطلب وإنهاء العامل وإعداد عامل نظيف عند إعادة المحاولة. لا تتغير الصيغ أو السياسة المالية أو بقية المحركات.

تشمل بوابةCI الملزمة اختبارات العامل الفعلي، أربع تركيباتCSV/XLSX، الحفظ والاستعادة وثمانية صادرات بفحص مستقلCSV/Decimal/OpenXML، وضوابط تحريف المصدر والنتيجة والجلسة وتعديل الطلب والإلغاء والرد المتأخر وإعادة المحاولة، وطفرات الحراس المحددة. تبقى جميع البوابات السابقة شروطًا قائمة.

الاختبارات المحلية والمراجعة المستقلة مرتبطة بمرشح الإصلاح نفسه؛ لا ينقل نجاح فرع التكامل إليه. الأدلة الخاصة تبقى خارج المصدر العام. سجلات الدور المحلي الأول تحفظ حالة البوابات حين أُنشئت؛ أدلة إعداد الإصدار اللاحقة مستقلة ومرتبطة بشجرتها الفعلية، ولا تعيد وصف بوابة غير منفذة كنجاح. إعادة القراءة على جهة العميل تحتاج فحص استجابة الواجهة وحدودها فعليًا قبل قبول الإصدار. يحمي الربط داخل التطبيق، ولا يثبت أصالة المستندات أو سلامة جهاز يسيطر فيه طرف على الشفرة كاملة.
