# نطاق الإصدار 0.4.40

يضيف هذا المرشح مراجعة أقسام PDF أصلي بخمسة أعمدة صريحة: التاريخ والمرجع والوصف والمدين والدائن، بعملة SAR ومنزلتين عشريتين. تظهر المراجعة داخل واجهة تراصف الحالية بالعربية والإنجليزية، وتبقى الحركات الصفرية والمجاميع والترحيلات وروابط الأصل قابلة للفحص.

لا ينشئ التحويل اعتمادًا ماليًا أو مطابقة تلقائية. يلزم اختيار جميع الحركات ومقترحات المراجع وتسجيل مراجعة صريحة؛ يستهلك التطبيق إذنًا مملوكًا للجلسة مرة واحدة. تحفظ الاستعادة سجل المراجعة دون إعادة سلطة الإذن. تُرفض الآثار المتجاوزة لميزانية البيانات قبل تسليمها للمستخدم.

يحافظ تصدير Excel على النص الحرفي، بما فيه علامات `_xHHHH_` ومحارف CR وDEL التي تتطلب ترميزًا خاصًا. تُرفض محارف بيانات المراجع والاستخراج التي لا يمكن تمثيلها بأمان، وتُعاد مطابقة جميع بيانات المصدر المشتق عند الحفظ والاستعادة والتصدير.

تتضمن بوابات المرشح اختبارات المصدر الأصلي ودورة المراجعة والحفظ والاستعادة، وحالات رفض وملكية وإلغاء وحدود موارد، وفحص Excel مستقل وطفرات واختبارات واجهة. تحفظ النتائج الفعلية خارج المصدر العام، ولا يُعد هذا الوصف إعلان نجاح CI أو النشر قبل تنفيذهما.

العينات اصطناعية فقط. يبقى تقييم عائلة مصدر ميدانية وقياس جهد المحاسب معلقين على عينات مأذون بها ومرجع مستقل؛ لا تتوسع هذه الدفعة إلى OCR أو أرصدة افتتاحية وختامية أو عملات وصيغ إضافية.
