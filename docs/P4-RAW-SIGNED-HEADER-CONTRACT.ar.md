# عقد P4: عنوانان خامان لأربعة حقول ومبلغ موقّع

الحالة: عقد وحقيقة أصلية قبل برمجة هذه العائلة. لا تنفيذ منتج قبل مراجعة مستقلة وتجميد root. هذا عقد منفصل عن الدور العربي في PDF، وعن nativeHeaderBand العام وطبقات Excel.

القبول محدود إلى صفين أصليين متجاورين في الصفحة الأصلية نفسها، وأربع خلايا فقط لكل صف. الزوج الأول بالضبط: `[Date, Reference, Description, Signed]` ثم `['', '', '', amount]`. الزوج الثاني بالضبط: `[Date, Reference, Description, Movement]` ثم `['', '', '', Signed amount]`. الصيغ هنا حساسة للنص الحرفي؛ لا مرادفات أو trim أو قاموس يزيد الدور. الصف الثاني ليس حركة ولا مبلغًا فاسدًا. لا يسمح أي منهما بعملة أو balance أو period أو debit/credit split، ولا field خامس.

المصدر هو RAW rows من native readFile مع قطوع يختارها المراجع، لا نص header مجمّع من nativeHeaderBand. أول صف هو mapping.header، وبعده صف واحد على الصفحة نفسها بلا صف بينهما. كلا الصفين وكل الخلايا الفارغة محفوظ في inventory وoriginal bytes. CSV المشتق وحده يملك header ثابتًا `[Date, Reference, Description, Amount]`؛ لا تعديل header المصدر أو استعمال CSV canonical لإثبات نص الأصل. لا IO/core/header-view/nativeHeaderBand تعديلات في نطاق التنفيذ المقترح، ولا glyph/byte-offset geometry أو Arabic headers أوسع.

عند page continuation يجب أن يوجد الزوج الكامل نفسه، بترتيبه الحرفي الأصلي وعلى الصفحة التالية المباشرة، قبل marker صريح مطابق لمرجع القسم. upper أو lower متغير أو ناقص أو موزع على صفحتين، وصف بينهما، أو تكرار الزوج داخل الصفحة يمنع الاستمرار. لا استعارة lower row قديم ولا forward fill. أسئلة حدود غير مؤكدة تبقى مرئية؛ whole derivation يرفض أي حركة/سياق مالي غير مفسر بلا إسقاط صامت.

شكل الدليل المقترح additive للعائلة الجديدة فقط: `headerBands?: SectionCellEvidence[][]`، كل band يحتوي ثماني خلايا literal أصلية (upper الأربع ثم lower الأربع، بما فيها الفراغ)، من initial band وكل carried band الذي يسبق الهدف. sourceHash/extractionHash/extractionRevision/sheet/row/page/column محفوظة في كل خلية. parent/continuation spans القديمة وسلوك headers القديم للعائلة ذات صف واحد لا يتغيران. full band يعاد إثباته قبل Apply، ويظهر أيضًا مع role evidence في sidecar. يحتاج هذا الشكل مراجعة مستقلة قبل implementation؛ frozen `headerBands` حقيقة physical cells لا API محرك مشتق.

كل حركة تحتاج تاريخًا صالحًا ومبلغًا موقّعًا وتفسير مرجع صريح من أصلها أو اقتراح مقبول مختار. own reference محفوظ حرفيًا. كل original row/page/values يبقى في provenance inventory، والحركات المثبتة وحدها ترتبط originalRow→derivedRow. whole reading يرفض corrupted/unknown/missing-date أو الحركة غير المختارة، ولو كان أول القسم صالحًا. الإشارات والأوصاف والمرجع محفوظة حرفيًا في CSV. المبالغ مستقلة بـ Python Decimal، ثم native readFile وprepareVerifiedSources يعيدان إثبات CSV مستقلًا؛ XXX داخلي للتحقق الحسابي وليس استنتاج عملة أو financial approval.

Inspect/Apply يعيدان hash وقراءة original PDF جديدة، مع مقارنة full rows/page maps/issues/notes/transforms. reviewer label/rationale والـ acknowledgements والاختيار والمراجعة والقراءة والدقة والأصل مربوطون بإيصال opaque مملوك ولمرة واحدة. لا mint من اقتراح أو نموذج ولا receipt clone. source/reviewer/mapping/revision/precision/selection change يبطل authority/pending publication. تفسير مقبول يدويًا على review محجوب قد يبقي legacy interpretation-only receipt؛ Apply المحجوب يستهلكه بلا مشتق أو مصدر أو قبول مالي.

حدود original8MiB/pages100/rows20,000/proposals4,096/evidence occurrences65,536 وyield256 موروثة، يسمح بخفضها فقط. كامل evidence الخلايا الثماني محسوب، لا اقتصاص للصف أو band للتجاوز. pre-abort قبل metadata traversal/clone؛ descriptors/plain bounded arrays/records/text قبل كل public copy، وcuts19/IDs قبل Set. native progress يراجع abort/generation قبل الصفحة التالية، loops وقبل النشر يراجعانها. لا وعد بمقاطعة hash أو getTextContent فورًا.

`audit/p4-raw-signed-header-v2/frozen/` حقيقة pre-engine مستقلة:26 PDF أصلية (8 positives مع exact CSV،18 negatives)، وأصل resource من9 صفحات و297 صفًا منها270 حركة/67,500 minor units، و23 action truths. generator يكتب PDF literal operators والصفحات مباشرة؛ لا product imports ولا reader output في truth. كل expected يحدد complete physical inventory، full band/parent/continuation citations، row links وsigned literal CSV/Money. immutable freeze يرفض إعادة التوليد في مكانه.

السلبية تشمل missing/changed/reversed/intervening/split-page bands، monetary context، debit/credit، five columns، late corruption وmissing date. actions تشمل byte/page/row/proposal/evidence budgets، native page1/row256 cancellation، pending source/reviewer invalidation، upper/lower/page/source/sign tamper، stale mapping/revision/precision، full band span tamper، opaque clone، public metadata قبل clone، والحركة غير المختارة. لا partial review/CSV/new authority من lifecycle/resource failure. expected empty proposals/links في structural negatives هي assertions عن accepted derivation فقط، ولا تحذف legacy diagnostics.

بوابة precode المحلية:27/27 native inventories/pages/source hashes/original bytes مطابقة (26 وأصل resource)، zero issues/cell notes،91/91 payload hashes وgenerator hash مطابق. تبقى قبول المنتج والـ actions بعد review+freeze: جميع eight exact CSV/Money/full citations وكل18 negatives/23 actions، وعدم تراجع العائلات السابقة وi18n. الدليل الخارجي `work/integration-continuation/p4/native-arabic-precode/native-replay-raw-header-v2.json`؛ وجود نجاح native import لا يدعي قبول P4 الحالي لهذه العائلة أو إثبات field/model عام.
