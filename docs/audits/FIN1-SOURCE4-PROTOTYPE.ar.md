## الصلاحية والحدود

الدالة `inspectFinancialHierarchySource4({name, original, expectedScope})` في [المصدر](../../lib/reconciliation/tb-financial-hierarchy-source.ts)، وأنواعها في [العقد البرمجي](../../lib/reconciliation/tb-financial-hierarchy-contract.ts). يجب تقديم `expectedScope` من سياق موثوق بمفاتيح الترويسات الاثني عشر حرفيًا؛ لا تستخرج الدالة سياق المقارنة من أول صف. لا تقرأ TB أو الخريطة أو دليل العرض، ولا تستنتج حسابًا مفقودًا أو صحة عضوية خريطة غير مقدمة.

النتيجة `kind: passive-source4-inspection` وحالتها `inspected` أو `blocked`؛ ليست قرار قبول مالي أو أهلية أو رأي تدقيق أو إثبات اكتمال اقتصادي. تعني `inspected` اكتمال الفحص المحلي دون مشكلة في عقده فقط. كل الحقول التشخيصية عند الحجب غير معتمدة. معادلة الأوراق تعرض فرقًا تشخيصيًا وتخضع للحد المالي؛ لا تستعمل قيمتها صفرًا كبرهان تغطية أو ملكية أو موافقة.

العائلة اسم CSV وحاوية UTF-8 وفاصل فاصلة إنجليزية فقط. لا XLSX أو PDF أو OCR أو أوراق متعددة. النطاق المدعوم SAR بدقتين، `functional / posted / actual / post-closing`، وتواريخ تقويمية صارمة مع `Period start <= Period end` و`As of = Period end`. اختلاف أي قيمة بين صف والنطاق المقدم يحجب؛ الهوية والنص حرفيان دون trim أو إكراه نوعي. يقبل القارئ LF وCRLF وCR بين السجلات واقتباس الفاصلة والسطر المتعدد وتهريب الاقتباس بتكراره؛ يحفظ محارف السطر داخل الحقل كما هي. BOM لا يزال من الأصل: ترويسة تحتويه مرفوضة بـHEADERS. UTF-8 غير الصالح مرفوض دون استبدال بمحارف بديلة.

## أصل البيانات والموارد

تلتقط الدالة نسخة أصل البايتات والاسم والنطاق تزامنيًا قبل أول await، بما فيه انتظار SHA256. لا مصدر سلطة لبصمة يقدمها المستدعي أو مخبأ Sheets. تعيد `source.original` و`source.sha256` و`source.byteLength` والاسم الملتقط، والنطاق الملتقط في `scope`.

`header` يحفظ الترويسة، و`inventory` سجلات البيانات بترتيب المصدر، بما فيها صف عرض أعمدة خاطئ أو Kind مجهول. لكل خلية في السجلات المكتملة، بما فيها الترويسة والحقول الزائدة، استشهاد يحمل SHA256 و`row` و`column` و`field` و`raw` و`lexeme`. `row` رقم سجل CSV والترويسة=1، وليس رقم سطر مادي. `raw` نص الحقل بعد فك اقتباس CSV فقط؛ `lexeme` الحقل المسلسل حرفيًا بما فيه اقتباساته. `serialized` نص السجل دون فاصل إنهائه. الأعمدة الزائدة لها field=null. ترتبط الأخطاء والعلاقات والسجلات بفهارس استشهاداتها.

العلاقات تأتي من Parent ID فقط. يحفظ جميع المتنافسين عند Node ID مكرر، ويشير كل edge إلى كل أرقام صفوف الأب المحتمل؛ لا أول فائز ولا إسقاط لتصنيع تفرد. يفحص وجود الأب ونوعه، الدورة، العمق، اتساق الفئة على كل علاقة، والأب غير الفارغ. العنوان جذر بعلاقة وفئة ومبلغ فارغين، ولا يملك أطفالًا مالية. غياب أي ورقة مالية يحجب، بما في ذلك ملف الترويسة أو العناوين وحدها.

المبلغ نص عشري ASCII بعلامة سالبة اختيارية، دون علامة + أو فصل آلاف أو أس علمي أو أصفار بادئة أو أكثر من رقمين كسريين. التحويل إلى BigInt دقيق، بلا floating point أو تقريب. الفراغ ليس صفرًا. يسمح بسالب الأصل المقابل وصفر صريح. يحفظ suppliedMinor ومجموع الأطفال المباشرين وفرق التحكم، مع أعضاء التحكم وصفوفهم. لا يضيف مبلغ الأب ثانية إلى فئة الورقة أو الإجماليات.

تحسب `leafSums` الأوراق مرة واحدة والفئات والأصول والالتزامات وحقوق الملكية ومعادلتها. تفحص الحدود للمدخلات والنتائج النهائية ومكونات المجاميع، وتسمح بإلغاء صحيح أثناء جمع BigInt قبل فحص النتيجة النهائية. عند بنية خاطئة/مبهمة لا تعرض مجموعة مساهمات تبدو قانونية؛ تكون leafSums=null. إذا كشف حساب المجاميع حد SUM فالنتيجة محجوبة وقد تحتفظ بقيمة تشخيصية دقيقة فوق الحد.
