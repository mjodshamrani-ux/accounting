# INV-1F-G1 فصل مصدر PDF عن إسقاط الأعمدة

**15 أكتوبر 2026 — مرشح محلي 0.4.53، دون تفعيل PDF ماليًا للمخزون**. الأساس المنشور المتحقق منه يبقى 0.4.52. تستند الدفعة إلى رأس أساس PDF ad9223cdd906c4ad50ba14338c021f1fb02e3386 فوق main المنشور ec0ae9b8bbfb2e1d45d699625860b92ebdc8c6d0. فحوص أساس PDF ودمجه منفصلة عن تحقق هذه الشفرة.

## المشكلة والوحدة المختارة

يرتبط العمل بـCH-10 وCH-12 وINV-1F. إسقاط أعمدة واحد للمستند لا يناسب جدولًا تتبدل أعمدته بين الصفحات، ولا أقسامًا تتغير رؤوسها محليًا. لا نفتح امتداد PDF قبل إثبات مصدر الأرقام والأبعاد. تنفذ هذه الوحدة **قراءة المصدر الهندسي فقط**، ثم تأتي أدوار الحقول، فالدليل المالي، فالعامل والجلسة، فالواجهة وExcel، فالتسليم. لا يعاد بناء القارئ أو كل محركات التسويات بالتوازي.

سقف الوحدة: إعادة استعمال الأصول المختومة التسعة عشر لا إنشاء قصة جديدة، و28 اختبارًا لوظيفة القراءة الجديدة، ومدقق مصدر مستقل مع ثمانية تحويرات قراءة وسبع طفرات شفرة. لا توسعة تلقائية إلى OCR أو أجهزة أكبر أو قياس كثافة.

## ما نُفذ

- جمع نصوص PDF في readGuardedPdf الخاص؛ يستعمله readPdf العام وreadNativePdfSource الجديد. بقيت حراس الخط وToUnicode والدفق الكامل والطبقات والصلاحيات والتدوير والنماذج والطلاء والتغطية والتباين والصور كما هي
- التقاط نسخة من البايتات قبل أول await، والتقاط حدود الأعمدة في مسار القراءة العام أيضًا. تمنع النسخة تبديل المصدر أثناء التهيئة غير المتزامنة؛ يظل الأصل الملتقط نفسه أساس SHA-256
- عقد native-pdf-source-1 يضم البصمة وحجم الأصل والصفحات وحدود عرضها والجزء النصي وموضعه وحجمه ورقم عنصره الأصلي. الإحداثيات بوحدات PDF من أسفل يسار الصفحة الظاهرة، مع الاحتفاظ بحدودها المطلقة. أرقام العناصر محلية للصفحة وتحتفظ بفجوات عناصر المسافات؛ ليست معرفات معاملات
- النص غير الفارغ يحتفظ بترتيب الحروف المثبت لدى حارس الطلاء، وبـglyphText وextractionText عند وجودهما. لا يستنتج القارئ المبلغ أو إشارته المحاسبية أو الدور أو العملة أو الأبعاد
- إعادة استعمال تحقق الهندسة والترميز وميزانية الأسطر دون استنتاج أعمدة. تبقى تحذيرات التداخل وحدود الصفحة في readingIssues مع الصفحة والسطر والسبب، مع حفظ النصين؛ ليست نتيجة صالحة تلقائيًا. على قارئ المجال التالي حلها أو حجب النتيجة وفق عقده
- لا يعاد ناتج هندسي قبل فحص الصفحات جميعًا. تستعاد الحراس ويُتلف مستند PDF.js في finally. التقدم يصف القراءة فقط؛ لا يدعي إنجاز مطابقة أو تحققًا ماليًا

لم تتغير readStockFile أو أهلية طلب المخزون أو المحرك أو الجلسة أو الحقول أو الواجهة. لا يقبل API مصدرًا هندسيًا سابقًا بوصفه أصلًا. لاحقًا يجب أن يعيد replay القراءة من البايتات، ولا تكفي البصمة وحدها لتصديق هندسة أرسلها عميل.

## الدليل المنفذ

نجحت وحدات القراءة الجديدة **28/28**. تغطي النصوص الحرفية والأصفار البادئة والإشارة والدقة والصفحة ومواضع الحروف، والتقاط الأصل وحدود الأعمدة قبل الانتظار، وعدم مشاركة مخبأ قابل للتعديل، وتعدد الصفحات، وأصل إحداثيات غير صفري. تشمل أيضًا تحذير التداخل مع بقاء النصين، والنص الأبيض والمخفي والمقصوص وضعيف التباين والطلاء المغطي والصورة، وفشل الدفق المتأخر وفشل الخط في الصفحة الأخيرة دون قبول بادئة سليمة، وحدود الحجم والصفحات. تستعمل ستة أصول Unicode مجمدة صالحة وسبعة تالفة دون تغييرها.

نجح الشامل **2439/2439**. نجح lint وTypeScript والبناء. أضيف أمرا الإثبات والطفرات إلى check وCI وإلى حارس الربط؛ نجح التحقق المحلي في **46 بوابة عائلة و85 كتلة shell**. هذا فحص YAML وأوامر محلي، وليس نتيجة GitHub Actions.

قرأ المسبار الفعلي ملفات PDF التسعة عشر بعد التحقق من أختام ملفات v2 الواحد والثمانين. طابق المدقق المستقل **56 صفحة و4,349 جزءًا نصيًا غير فارغ و4,042 استشهادًا ماديًا**، و49 حقيقة مصدرية في الحالات السبع القابلة للتفسير، بما فيها الفرق ونقص الدليل. يفحص القيم والكميات والوحدات والأبعاد بمواقعها المعينة ودقتها، ولا يكتفي بالمجموع. هذه 49 حقيقة متكررة عبر عروض/نقائض للقصة ذات السجلات السبعة؛ ليست 49 قصة أو نتيجة أنجزها محرك المخزون من PDF.

يحفظ القارئ نص الحالات الاثنتي عشرة ذات الخطأ المالي أيضًا؛ صلاحية النص الهندسية لا تعني صحة النطاق أو الإجمالي أو اكتمال الملف. يظل الأوراكل المالي يصنفها source-error. ويظل baseline المنتج **0/4** على عروض PDF الموجبة مع رفض الملفات التسعة عشر بـSTOCK_SOURCE. أعيد تشغيل ضابط CSV والجلسة وExcel المستقل، فبقيت الحقائق السبع وروابطها و28 عضوًا صحيحًا.

قبل المدقق إعادة تسلسل JSON سليمة وكشف ثمانية تحويرات بـAssertionError: تبديل مبلغين مع ثبات المجموع، والكمية، والبعد، وبصمة مصدر أجنبي، وحذف آخر صفحة، وملكية صفحة خاطئة، وموضع خاطئ، وتكرار رقم العنصر. وكشفت الوحدات سبع طفرات شفرة في نسخ خاصة: رفع التقاط الأصل، ونقل الصفحات إلى الرقم نفسه، وإلغاء أصل الإحداثيات، وحذف تحذيرات القراءة، وتجاوز حراس الطلاء والخط والدفق. لم تعدّل الطفرات المصدر الحقيقي، ولا يعد خطأ البنية التحتية أو توقف التنفيذ كشفًا ناجحًا.

نجح أيضًا test:browser بقائمة من **34 فحصًا مسمى**، وتشمل مسارات القراءة الحالية والعامل وAR/EN والمراجعة والحفظ والتصدير. هي انحدارات للواجهة القائمة؛ لا توجد واجهة G1 مالية جديدة. لم ترصد اتصالات خارجية أو طلبات POST.

نجحت **12 واقعة تحقق** لمسار PDF الطويل القائم: قراءة 70 و100 صفحة، والتنقل المحدود، وفشل الصفحة الأخيرة والإلغاء واستعادة العامل. طابق مدقق OpenXML المستقل صادر الـ70 صفحة: **2,240 زوجًا و4,480 عضوًا** دون زوج معتمد خاطئ أو مفقود، والقيم والأصل وآخر صفحة والجلسة. شاهد معروف الهيكل، لا بنية مخزون جديدة أو قياس أجهزة ضعيفة. ظلت تعارضات أرصدة المورد ونقص تغطية الفترة ظاهرة؛ لا إثبات Full Balance Reconciliation من نجاح مطابقة المعاملات.

## الإخفاقات المحفوظة أثناء التطوير

افترض المدقق الجديد أولًا أن كل عبارة المصدر تقابل عنصر PDF.js واحدًا، فأخفق TOKEN_COUNT؛ قد يفصل القارئ العبارة عند المسافة. صُحح مدقق المقارنة الجديد ليثبت كل حرف ظاهر بموضعه الأصلي، مع السماح بفجوة عند مسافة موجودة فعلًا في الأصل فقط. لم يتغير مولد الأساس أو مدققه أو ختمه أو توقعاته المالية.

سجلت طفرة رفع التقاط الأصل رفضًا عند القراءة، لكن ذلك لم يثبت كشفًا باختبار تأكيدي. صُحح اختبار الالتقاط ليؤكد صراحة نجاح القراءة من الأصل الملتقط؛ بعده كشفت الطفرة بـERR_ASSERTION. بقي حارس تصنيف الطفرات نفسه دون تخفيف.

## المتبقي بالترتيب

1. **G2 دور الحقل والحدود:** عائلة PDF محلية للجدول/الصفحة، مع الربط بأجزاء النص الأصلية ورؤوس الأدوار والأب والدفعة والاستمرار والنطاق والترقيم. لا تقسيم حسب المسافة أو أبعاد موروثة من قسم أجنبي
2. **G3 الحساب:** تحويل القيم المثبتة للنواة القائمة، وإنجاز الأربع الموجبة والفرق وحالتي نقص الدليل، مع حفظ أخطاء المصدر الاثني عشر وسياسة حجب المال القائمة
3. **G4 الأصل والعامل:** قبول PDF المحدد بعد العقد فقط، وإعادة القراءة في reconcile/save/restore/export، والقرار المرتبط بالأعضاء الحقيقيين وحماية الرد القديم أو الأجنبي
4. **G5 تجربة المستخدم والصادر:** الرفع المشترك و3D وAR/EN والاستدلال الحتمي، واستشهادات الصفحة/الحدود في Excel ومدقق مستقل، ثم المتصفح الحقيقي
5. **G6 التسليم:** نجاح CI للرأس نفسه ثم الدمج والنشر والتحقق الحي. لا تنسب نتائج 0.4.52 لهذا المرشح ولا تعلن نشره قبل الدليل

لا يغلق G1 تنوع PDF الميداني أو العربية أو الصور أو OCR أو ضعف الأجهزة أو سعة الشركات. العائلتان وأربعة العروض من كاتب واحد وقصة واحدة معلومة للمطور؛ ليست holdout. لا نموذج أو اتصال خارجي أو تغيير للخط أو الشعار أو التصميم أو حدود الملفات بهذه الوحدة. رُفع رقم مرشح التطبيق لأن القارئ المشترك داخل حزمة العامل تغير، مع بقاء إصدارات المحركات والجلسات كما هي.
