# إعداد الإصدار 0.4.44

يجمع هذا المرشح المحلي TB الرأسي بأدوار ومكونات مقدمة، والبنك بسحب وإيداع صريحين، وسجل الأصول الطويل بأربعة مكونات مقدمة، فوق main المنشور0.4.43. يحفظ ربط GL–TB بأصول الطلب وجلسة الاستعادة وبايتاتها، واختباراته ومدقق صادراته وطفراته وبوابات CI المنشورة. لا يشتق مكونات مالية مفقودة أو حركة من رصيد.

يحفظ التكامل تحسينات مساحة العمل المشتركة من المرشح المراجع، والعائلات القديمة ومكونات المصدر الأصلية وتنسيقات خلايا الأوراق. لم يتغير إصدار المحرك أو تنسيق الجلسة أو التبعيات. تفاصيل الحدود في [ملاحظات التكامل](SOURCE-FAMILIES-INTEGRATION.ar.md).

أُعيد تطبيق المرشح المراجع فوق الرأس المنشور الفعلي مع حل تعارضات الإصدار والعامل والقائمة العامة. هذا إعداد محلي فقط؛ قبول الشجرة النهائية يحتاج فحوصًا ومراجعة مستقلة جديدة. لا تنسب نتائج الفروع السابقة إلى هذه الشجرة ولا تدعي هذه الوثيقة تشغيل متصفح أو CI بعيد أو رفعًا أو دمجًا أو نشرًا. تبقى الأدلة الخاصة خارج مصدر النشر.
