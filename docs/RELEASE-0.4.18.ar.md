# تراصف 0.4.18 — حفظ أدوار الأرقام قبل المطابقة

نجح 994 اختبارًا محليًا دون تخطي. على GitHub نجح 982 وتخطى 12 يحتاج إلى ملفات محلية خاصة، ولم يفشل أي اختبار. كشفت المجموعة 103 أخطاء محاسبية أدخلت عمدًا، ونجح 55 اختبار Python مستقلًا.

نجحت الحالات الجديدة العشر بعد أن أعاد خط الأساس إنتاج ثمانية اعتمادات غير سليمة، مع إبقاء الاختبارين الإيجابيين ناجحين. فُحصت 20 ورقة عمل جديدة مباشرة وبعد الاستعادة، وتحققت واجهة المتصفح من أربعة تنزيلات للحالات الجديدة. فحص النشر الحي شملها مع العائلات السابقة: 18 ورقة عمل فحصتها أداة OOXML مستقلة.

تطابقت شيفرة الموقع الحي والعامل المحاسبي المنفذ مع حزمة GitHub الفعلية ببصمات SHA-256. اجتاز PDF نصي من 70 صفحة فحص 2240 مطابقة مطلوبة وحفظ كل أعضائها، دون خطأ أو فقد في العينة. لم ترصد تجربة الرفع والتصدير الحية طلبات خارجية أو إرسالًا للملفات.

هذه أدلة تطوير وانحدار مصطنعة وليست تجربة عميل مستقلة. PDF الكبير ذو تخطيط معلوم ومراجعة وحدود أعمدة صريحة، وتعارضات الأرصدة تمنع إعلان التسوية الكاملة. تبقى الصور العربية للمراجعة، وتظل المجموعات العامة للفواتير والتوزيعات الجزئية خارج نطاق التصحيح. اختبار واجهة النموذج المحلي لا يثبت تدريبًا أو جودة نموذج فعلي.

لم تُغيّر النتائج التاريخية الفاشلة لإظهار النجاح. ملفات خط الأساس والمرشح محفوظة، وسجل النشر منفصل عنهما. التوثيق اللاحق ودليل الفحص لا يغيران حزمة الموقع المنشورة.
