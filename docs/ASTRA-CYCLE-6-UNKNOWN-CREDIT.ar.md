# تصحيح دليل الإشعار مجهول النوع — 0.4.18

## الخطأ المثبت

بعد نشر 0.4.17، كشف التدقيق النهائي مسارًا لم تغطه عائلة F03 الأولى: وجود `Credit Note No` أو `رقم الإشعار الدائن` بجوار `Invoice No` مع نوع مستند فارغ. كان رقم الإشعار يُهمل، ويعتمد المحرك رقم الفاتورة المشترك عند تساوي المبلغ والتاريخ. مثال CN-701 مقابل CN-799 والفاتورة INV-401 ينتج ربطًا خاطئًا.

كُتب [العقد المستقل](../audit/related-invoice/unknown-role/contract.json) قبل تشغيل النسخة القديمة، وجُمّدت [بصمات المصادر](../audit/related-invoice/unknown-role/source-manifest.json). أعيد إنتاج الخطأ في 8 تمثيلات من 10 باستخدام XLSX وCSV فعليين بالعربية والإنجليزية. بقي اختبارا الفاتورة العادية ناجحين. تحفظ [نتائج 0.4.17 وملفاتها](../audit/related-invoice/unknown-role/baseline-0417) كما هي ولا تستبدلها نتائج التصحيح.

## القرار المحاسبي

الرقم غير الفارغ تحت عنوان صريح لرقم الإشعار، مع نوع غير متحقق، دليل يحتاج مراجعة. لا يخمّن المحرك أن الصف إشعار دائن، ولا يثبت أي هوية جديدة اعتمادًا على شكل الرقم أو رأي AI. يحفظ الرقم وعنوانه في `Retained Evidence` ويذكر سبب عدم اعتماد الربط.

يستخدم قراءة الأعمدة الآمنة الموجودة: العنوان المتكرر، والخلية المخفية، والنص الذي يشبه صيغة أو خطأ، تظل أسبابًا للمراجعة. اختيار مرجع آخر لا يلغي التحذير. عمود رقم إشعار فارغ في قالب فاتورة عادية لا يمنع المطابقة. صفوف الملف المثبتة تستمر في الإنجاز؛ لا يُرفض الملف بسبب صف آخر غير مثبت.

لا يضيف هذا التصحيح استدلالًا إيجابيًا لصور أو أنواع جديدة، ولا يغيّر الأرصدة أو قواعد المجموعات أو حدود الأداء. `unverifiedCreditNoteNumber` دليل محفوظ فقط؛ لا يستخدم لتقسيم المنافسين أو منح هوية لمجموعة.

## التحقق وحدوده

نجحت الحالات العشر بعد التصحيح. يقرأ اختبار مستقل مكتوب بلغة Python أجزاء OOXML، ويقارن أرقام الإشعارات الأصلية وعناوينها والمبالغ والصفوف وحالة المراجعة ونوع المستند، مع اختبار التصدير المباشر وبعد استعادة الجلسة. يتطلب العقد إنجاز الفاتورة العادية، فلا يمكن اجتيازه بمنع المطابقة عمومًا.

أضيفت 17 حالة انحدار واختباران لتخريب الشيفرة عمدًا: إزالة تحذير الدور وحذف الرقم المحفوظ. فحص Oracle نفسه يتضمن 8 تحريفات للأرقام والأدوار وحالة المراجعة والصفوف. واجهة المتصفح ترفع الملف الأصلي وتستخدم العامل الفعلي وتحفظ الجلسة وتستعيدها ثم تنزّل Excel، دون حقن صفوف أو نتائج جاهزة.

دليل النشر النهائي لنسخة 0.4.17 محفوظ في [السجل المستقل](../audit/related-invoice/live-0417/release.json). نتائج مرشح 0.4.18 محلية حتى تجتاز بوابات GitHub وفحص الموقع الحي؛ يسجل دليل النشر اللاحق منفصلًا عن هذا القرار الأولي.

هذه عينات تطوير وانحدار مصطنعة وليست Holdout أو ملفات عملاء. الصور العربية تبقى مسودة للمراجعة، والتوزيع العام N:M والدفع الجزئي غير المنجزين يظلان خارج حدود هذا التصحيح. لا تدّعي هذه النتائج دقة شاملة لكل ملف أو تدريبًا فعليًا لنموذج ذكاء اصطناعي.
