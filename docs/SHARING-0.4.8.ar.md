# مشاركة تراصف 0.4.8

الرابط الدائم: https://mjodshamrani-ux.github.io/accounting/

هذه النسخة تعتمد المصدر الموحّد `bb70d89` الذي يجمع تعديلات كلاود ودورة موثوقية 0.4.6 وإصلاحات قبول 0.4.7. إصدار الواجهة 0.4.8، والمحرك بقي `0.3.14-experimental` دون تعديل في قواعد القراءة أو المطابقة.

## بطاقة المشاركة

صورة PNG بقياس 1200 × 630، بخلفية بيضاء وشعار تراصف المتجهي الأصلي وخط ثمانية الأصلي وعبارة «وضوح أكثر في تسوياتك». صُممت لتبقى مقروءة بالحجم الصغير، دون إطار مزيف أو تفاصيل واجهة المنصة داخل الصورة.

- الصورة: `public/brand/tarasuf-share-v048.png`
- بيانات Open Graph وX والعنوان والوصف والرابط الدائم موجودة في `index.html`، دون اعتماد على JavaScript
- اسم الصورة يحمل إصدارها لتجنب إعادة استخدام صورة قديمة عند تحديث التصميم
- أيقونتا PNG بحجمي 180 و32 مع إبقاء شعار SVG
- الصور والخطوط محلية، دون متتبعات أو طلبات بيانات إضافية
- `pnpm brand:social` يعيد توليد الأصول باستخدام Playwright والخطوط والشعار الموجودين في المستودع
- البناء يفحص وجود بيانات المشاركة واتساقها ووجود الصورة الفعلية ونوعها وأبعادها وحجمها

يحافظ فحص الخصوصية على منع الموارد الخارجية. الاستثناء الوحيد رابط canonical ثابت لنفس عنوان الموقع؛ هو وصف للرابط ولا ينشئ طلب بيانات.

شكل الإطار ومكان العنوان وقص الصورة تحدده المنصة المستقبلة، وقد تحتفظ بمعاينة سابقة مؤقتًا. لا يمكن للموقع فرض شكل واجهة X أو واتساب أو تغيير معاينة رسالة قديمة. الرابط `https://mjodshamrani-ux.github.io/accounting/?v=0.4.8` يصل إلى النسخة نفسها ويمكن استخدامه عند بقاء معاينة قديمة مخزنة.
