# خطط تطوير المحركات

هذه خطط تنفيذ مستقبلية فوق أساس 0.4.48، وليست قائمة ميزات أُنجزت بهذه الدفعة التوثيقية. لكل نوع عقده وقبول مستقل. الترتيب التنفيذي المرجعي في [CURRENT-PLAN](../CURRENT-PLAN.ar.md)، ولا يلزم إنهاء جميع الأنواع قبل تسليم تحسن مفيد في نوع واحد.

يشترك الجميع في [C-0 إلى C-4](common.ar.md)، و[بوابة الجودة](../reference/QUALITY.ar.md)، و[AI/OCR](../reference/AI-AND-OCR.ar.md)، و[الهوية](../reference/DESIGN.ar.md). محرك البنك يتضمن مسار أرصدة وبنود مستقلًا؛ ليس زرًا عامًا يجعل كل تطابق حركات تسوية كاملة.

[سجل التحديات](../reference/CHALLENGES.ar.md) يشرح أصعب حالة لكل مجال، ومصدر الألم للمحاسب، وخطر الحل السطحي، والدليل المطلوب، ومعايير قبول مقترحة. اربط كل دفعة بمعرف التحدي وخطة المجال، وافحص التغطية الحالية قبل إضافة اختبار أو إعادة كتابة محرك. سجل المخاطر لا يعلن عيوبًا مؤكدة أو قدرات مكتملة.

[ذاكرة التطوير](../reference/DEVELOPMENT-LESSONS.ar.md) تحفظ ما أخطأنا فيه وحدود إصلاحه، و[بروتوكول تنوع المصادر](source-diversity.ar.md) يحدد اختبار البنى والمنتجين والدلالة والسعة. يطبق DIV داخل C-0 وخطة المجال، ولا يضيف نوع تسوية أو يغير ترتيب التنفيذ. لا نعد زيادة الصفوف أو تغيير الأرقام فهمًا لهيكل جديد.

## تعريف الدفعة المكتملة

تحمل معرفًا ثابتًا، عقدًا ومصدرًا واختبارات مستقلة، وتعمل من الرفع حتى Excel والاستعادة والمساعد ضمن الواجهة المشتركة. لا يكفي إكمال دالة مقارنة أو نجاح demo. نتيجة القبول تعلن العائلات المدعومة وما بقي للمراجعة وما لا يزال خارج النطاق.

## توسع الحسابات والخدمة المؤسسية

توسع الخدمة إلى **حسابات ولوحة مالك ومؤسسات وتجارب مجانية واشتراكات** له [خطة مستقلة ACC-0 إلى ACC-6](accounts-privacy-business.ar.md) بحدود بيانات واختبارات أمان. هو مسار تجاري مستقبلي، وليس نوع تسوية ثالث عشر أو تغييرًا لسلطة المحركات. تتضمن الخطة أيضًا SSO وقوالب محلية وحزم مراجعة ونشرًا مؤسسيًا كخيارات مقيدة بالدليل.

## التوسع إلى أنواع جديدة لاحقًا

الرؤية تشمل تسويات أخرى، مثل الضرائب والحسابات الوسيطة الإضافية والإيرادات المؤجلة والقروض والإيجارات والتوحيد. هذه **مرشحات اكتشاف غير منفذة وغير مجدولة**، وليست عناصر نضيفها تلقائيًا للقائمة. يبدأ النوع الجديد بسؤال محاسبي واضح، مصدرَي حقيقة أو الأدلة اللازمة، سياسة الإشارات والعملة والفترة، شكل ورقة العمل، ومجموعة قبول مستقلة. لا يحتسب كنوع جديد تغيير اسم أحد الأنواع الحالية فقط.

تحديد أولوية التوسع يتبع قيمة الاستخدام وتكراره وScope Fit وكلفة إعداد القالب وحجم الخطأ الممكن. توسيع نوع قائم إلى دخل أو تدفقات نقدية، أو احتساب ضريبة/استهلاك/تقييم، يحتاج عقدًا جديدًا؛ لا يورث صلاحية من المركز المالي أو سجل القيم المرحّلة.

## طبقة الذكاء والمساعد المحلي

تفصل [خطة AI المحلية](ai-local-assistant.ar.md) AI-1 وAI-2 وAI-3 وOCR-1 إلى دفعات بعقود وصلاحيات وأدلة وأجهزة فعلية. نقطة البداية تفسير واحد مفيد مع محرك حتمي مستقل، ثم شات يشرح الأدلة وقراءة مرئية محدودة عند ثبوتها. تتضمن ميزانية موارد مقترحة، وفصلًا بين الدقة الخام والنتيجة المقبولة والمنفعة، ومنع إرسال البيانات أو فرض نموذج على جهاز المستخدم. ليست هذه إضافة مفعلة أو توسعة آلية لعقود التسويات.
