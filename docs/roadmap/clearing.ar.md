# CLR — المقاصة داخل الحساب

**الحالي:** حساب واحد بعملة وفترة ونطاق محددين، مرجع كامل أو قرار موثق؛ صافي الحساب صفر لا يكفي. [clearing.ts](../../lib/reconciliation/clearing.ts) و[clearing-io.ts](../../lib/reconciliation/clearing-io.ts).

## CLR-1 مجموعة مقاصة كاملة — مخطط بعد C-0 وC-1

راجع تكوين المجموعات عندما يعاد استخدام المرجع، ويقابل قيد عدة قيود، وتوجد عكوس أو إعادة ترحيل. افصل معرف الصف الفيزيائي عن رقم مستند قد يتكرر. قيد صفر أو وصف بلا مبلغ ليس إذنًا لإسقاط دليل منافس.

المخرج: حدود مجموعة معلنة، كل عضو واستخدامه وسبب ضمه، ومتـبقٍ ظاهر. لا تختار مجموعة جزئية تساوي صفرًا بينما بقية المرجع غير محسومة. لا تسمح بمقاصة بين حسابين أو عملتين أو نطاقين لتجميل الصافي.

قبول: مجموعة واحدة مثبتة؛ مجموعتان تصفران الحساب دون علاقة؛ مرجع متكرر في فترة أخرى؛ عكس مرتبط وقيد بديل؛ عضو مكرر؛ صف تالف متصل؛ صف تالف مستقل؛ تبديل ترتيب الصفوف. يبقى قيد كامل غير محسوم مرئيًا، وتثبت شروط العزل قبل توسيع النتيجة الجزئية.

## CLR-2 مصادر متعددة الأقسام ومراجعة أسرع — مخطط بعد CLR-1

أضف عائلة كشف حساب بأرصدة وترحيل بين الصفحات دون عدّ الرصيد حركة. استخرج بيانات النطاق الصريحة مع مصدرها، واعرض للمحاسب فقط تعارضها أو غيابها. القرار اليدوي يحمل سببًا وأعضاء محددين، ويبطل عند تغيير القراءة؛ لا يسمى إثباتًا آليًا.

قبول: رأس مكرر، مجموع صفحة، رصيد افتتاحي، ختام لا يساوي الحركة، قرار ثم إعادة فتح وإلغاء واستعادة وتصدير. يوضح Excel ما صُفّي وما بقي ولأي سبب، حتى عندما صافي الحساب العام صفر.
