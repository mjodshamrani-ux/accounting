# P4: الحركة والرصيد الجاري المقدم

الإصدار `0.4.42` مرشح محلي للعائلة `P4_RUNNING_BALANCE_SAR2_V1`. النشر معلّق إلى نجاح البوابات العامة وCI والمراجعة المستقلة للمرشح النهائي. يثبت التنفيذ اتساق الحركات والأرصدة المقدمة داخل مصدر واحد وفق القالب المحدد؛ ولا يمثل اختبار الحالات الاصطناعية تحققًا ميدانيًا أو إثبات اكتمال مستندات خارجية أو قياس جهد المراجع.

## المصدر والحساب

PDF نصي أصلي لحساب واحد وكشف واحد وفترة واحدة، بعملة SAR ودقة منزلتين ومنظور `debit-minus-credit`. حدود الأعمدة ثابتة `[10,25,40,65,77,88]`، والرأس حرفيًا `Seq, Date, Reference, Description, Debit, Credit, Balance`. تتكرر في كل صفحة بيانات الهوية والفترة والعملة والمنظور ورقم الصفحة، مع العلامة `SYNTHETIC ONLY` الخاصة بالقالب الحالي. ترتيب المصدر الفيزيائي هو سلطة القراءة؛ لا تعيد الواجهة ترتيب الصفحات أو الحركات بحسب التاريخ.

المعادلة الوحيدة بالوحدة الصغرى الصحيحة وBigInt: `nextProvided = previousProvided + debitProvided - creditProvided`. الفرق التشخيصي هو المقدم ناقص المحسوب. كلا مكوني الحركة مكتوب صراحة؛ الفراغ ليس صفرًا، ولا يجوز جانبان موجبان. الحركة الصفرية باقية في التسلسل والعدادات. الرصيد موقع اختياريًا بـ`-`؛ ترفض العلامات الأخرى والسالب الصفري والتقريب والفواصل والأسس. الحد الشامل لكل مكون ورصيد ومجموع مكونات هو `10^14` وحدة صغرى، بما فيها الخطوات الوسيطة.

`Seq` نص مقدم متصل من 1 دون فجوة أو تكرار، وليس رقمًا يولّده المنتج. هويات الكشف والحساب والأقسام تتبع `[A-Za-z0-9][A-Za-z0-9._/-]{0,63}` حرفيًا. التواريخ ISO صحيحة ضمن 1900–2100 وداخل الفترة؛ دور الافتتاح بتاريخ بداية الفترة ودور الإقفال بتاريخ نهايتها. يسمح بتاريخ حركة أقدم داخل الفترة مع حفظ ترتيبها المقدم.

الرصيد عام للحساب ولا يعاد ضبطه عند قسم فاتورة جديد. تتحقق أدوار الافتتاح والمتابعة والترحيل والإقفال ومجاميع القسم والصفحة والكشف وعداداتها مع عضوياتها الأصلية. لا تدخل صفوف الضوابط في الحركات. المرجع الفارغ يحتاج اقتراحًا مدعومًا بخلايا الأب والمتابعات ومراجعة صريحة. فشل متأخر يحجب الملف كله عن الاشتقاق؛ يبقى الجرد والتشخيص للتفسير.

## المراجعة والأثر المحلي

الواجهة مساحة مراجعة مستقلة. يلزم اختيار جميع الحركات وجميع اقتراحات المرجع اللازمة واسم المراجع وسببه وتسعة إقرارات تغطي الصفوف وأدوار المرجع والمكونين والمنظور والعملة والأرصدة والتسلسل والمجاميع وفهم المصدر المشتق. الإيصال كائن مملوك للجلسة الحية أحادي الاستخدام، يستهلك قبل الانتظار حتى عند فشل التطبيق أو إلغائه. تغيّر المصدر أو السياق أو الاختيار أو المراجع أو جيل العملية يمنع نشر عملية قديمة. النسخ يأخذ مدخلًا مملوكًا قبل الانتظار، فلا يغير تعديل المستدعي اللاحق أدلته.

الأثر `P4_RUNNING_BALANCE_ARTIFACT_V1` يحفظ PDF الأصلي وCSV بسبعة حقول ونصوص `Seq/Balance` الأصلية، والجرد وروابط الحركات والخطوات والضوابط وعضوياتها والأدلة ذات مدى UTF-16 وبصمات المصدر والاستخراج والسياق والاختيار والمراجع. المرجع المفسر مرتبط بأدلة اقتراحه؛ الخلية الأصلية الفارغة تبقى في الجرد. الحفظ والاستعادة والتصدير تعيد القراءة والتحقق من الأصل والمبالغ والعضوية والترتيب. الإيصال المستعاد تاريخ مراجعة، دون سلطة تطبيق جديدة.

`financialApproval=false` و`scopeConfirmed=false` ثابتان. لا يعيّن هذا الأثر أرصدة افتتاحية أو ختامية أو نطاقًا في مقارنة أخرى، ولا يفتح مطابقة مالية تلقائية. تصدير XLSX يحفظ النص حرفيًا دون صيغ في `DerivedReading` و`OriginalInventory` و`SourceCellEvidence` و`BalanceSteps` و`Controls` و`ControlMembers` و`ReviewHistory` و`OriginalPdf`. الأدلة والعضويات صفوف مستقلة، وPDF محفوظ في قطع نصية محدودة. يبقى CSV ملفًا نصيًا؛ تفسير برنامج خارجي له ليس نوع خلية يملكه الأثر.

## الحدود والإلغاء

السقوف: PDF وCSV كل منهما 8MiB مستقلًا، 100 صفحة، 20000 صف، 32767 وحدة UTF-16 لكل خلية، 4096 اقتراح، 65536 وقوع دليل، مليون عقدة plain data، عشرة ملايين وحدة نصية إجمالية، وعمق 14. تشمل الميزانية مفاتيح البيانات وفهارس المصفوفات ونسخ الأدلة المتكررة فعلًا. الخيارات تخفض الحدود ولا ترفعها؛ كون ملف تحت سقف واحد لا يضمن قبول جميع تركيبات الموارد.

تفحص الأنواع وdescriptors قبل النسخ وترفض getters والبيانات غير البسيطة. الإلغاء المسبق يسبق traversal، ثم يفحص عند تقدم الصفحات وكل 256 صفًا وقبل نشر الأثر. لا وعد بمقاطعة hash أو استخراج نص الصفحة التزامني فورًا. يفحص الأثر المجمع قبل تسليمه، فتُرفض نتيجة ذات مصدر صالح إذا تجاوزت أدلتها المتكررة ميزانية الحفظ والتصدير.

## الدليل وإعادة التنفيذ

حزمة [المدخلات المجمدة](../audit/running-balance/README.md) تضم 44 حالة مؤلفة قبل كود المنتج: ثماني موجبات و36 سلبية. تحفظ نسخ حقائقها وPDF وCSV المتوقع دون تغيير؛ دورات الموجبات الثماني تشمل القراءة والاختيار والمراجعة والتطبيق والحفظ والاستعادة وExcel. الأفعال A01–A24 تشمل الملكية والتزوير والإلغاء والحدود وتغيير الهويات والفترة.

حالة Unicode منفصلة مؤلفة بعد التنفيذ وقبل رصد المنتج، وليست جزءًا من الأوراكل المجمد ذي 44 حالة أو دليل قبول سابق للكود. تختبر حرفًا خارج BMP ومداه UTF-16 عبر القراءة والأثر والاستعادة وExcel. لذلك ينتج سائق الدليل الحالي تسع دورات موجبة و18 مصنفًا، ويختبر المتصفح 22 حالة عبر العربية والإنجليزية مع 36 تنزيل Excel مباشرًا ومستعادًا. هذه أعداد corpus الاختبار، وليست ادعاء تحقق ميداني.

الأوامر الملزمة:

- `pnpm test:running-balance`: الملفات الأربعة الخاصة بالتصنيف والجلسة والسلطة والانحدار الأصلي.
- `pnpm test:running-balance:proof`: تحقق بصمة الحزمة وإنتاج الدليل ثم فاحص Python مستقل باستخدام Decimal وZIP/XML، دون استيراد حساب المنتج.
- `pnpm test:running-balance:mutations`: 11 طفرة دلالية في نسخ مؤقتة؛ أخطاء البنية التحتية وsyntax ليست قتلًا لطفرة.
- `pnpm test:running-balance:browser`: واجهة Chrome الحقيقية بالعربية والإنجليزية ثم فحص مستقل لتنزيلات كل لغة.

تستخدم التقارير `RUNNING_SESSION_REPORT_DIR` و`RUNNING_REPORT_DIR` و`RUNNING_MUTATION_REPORT_DIR` و`RUNNING_BROWSER_REPORT_DIR`. تضبط أوامر package افتراضيًا مسارات `work/running-balance-*` المهملة من Git، ويضبط CI مسارات `${{ runner.temp }}`. يحتاج المتصفح build ومثبت Chromium، ويقبل `MIZAN_CHROMIUM` لمسار Chrome المحلي. أضيفت البوابات إلى `pnpm check` وCI مع إبقاء البوابات السابقة. تبقى التقارير الخام على المشغل المؤقت؛ المرفوع للنشر هو `dist` الذي اجتاز مراجعة المحتوى.
