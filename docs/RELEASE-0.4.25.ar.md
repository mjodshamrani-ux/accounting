# 0.4.25 — مصدر صورة بعمودي المدين والدائن

أضيفت عائلة واحدة للمصدر البصري المراجع: جدول PNG بعمودي مدين ودائن، بالعربية والإنجليزية. تعاد قراءة الأصل ومعاني الأعمدة عند المقارنة والحفظ والاستعادة والتصدير. يبقى سجل إصدار 1 للمبلغ الموقع متوافقًا، ويستخدم الأساس المنفصل إصدار 2. لا تدخل القيمة المفقودة كصفر ولا تُقاص قيمتان غير صفريتين في الصف نفسه. [العقد وحدود العائلة وجهد المراجعة](P6-REVIEWED-SPLIT-IMAGE.ar.md).

نسخة الواجهة 0.4.25. يبقى إصدار قواعد الحساب 0.3.26-experimental؛ هذه الدفعة توسع عقد المصدر البصري وتستخدم حساب المدين والدائن القائم، دون تعديل قواعد اعتماد المطابقة.

## التحقق المحلي

- 1,096 اختبار وحدة ناجحًا وفحص TypeScript والبناء.
- كشف الأعطال المتعمدة الثلاثة الجديدة: خلط أساس المبلغ، وتجاوز إصدار الجدول، وتجاوز إصدار المصدر. يشمل كتالوج CI الكامل 134 عطلًا متعمدًا.
- فاحص مستقل للبكسلات وملاحظات OCR الأصلية والقصاصات والصفوف والسياق وإكسل، مع أربعة اختبارات تكشف تحريفات تشمل اختراع صفر وحذف خطأ وتغيير إشارة وحذف الصورة.
- ثلاث مطابقات سليمة فقط وثلاثة أخطاء ظاهرة لكل عينة عربية وإنجليزية. فُحصت أربعة تصديرات من إعادة الحساب والحفظ والاستعادة، وستة من الواجهة بالعربية والإنجليزية والجوال والاستعادة.
- حفظ الصورة الأصلية وسجل المصدر كاملًا في إكسل، وإبقاء الخانة المفقودة والقيم السالبة وصف الجانبين للمراجعة، دون إعلان اكتمال الأرصدة.

أخفقت محاولة متزامنة ثقيلة في حد زمن مقارنة 20 ألف حركة وفي مهلة خط أساس اختبار الأعطال. نجحت الإعادة المنفصلة مع الحدود الزمنية نفسها؛ لم تُخفّف الاختبارات. تحفظ بصمات المحاولات ونتائجها في [سجل التحقق](../audit/visual-split/local-validation.json)، وتبقى السجلات المحلية الكاملة التي تختبر ملفات خاصة خارج المستودع العام.

نجحت دورة المتصفح المركزة قبل تغيير صلاحيات البيئة. توقفت الدورة المحلية الكاملة عند الانقطاع، ثم منعت البيئة المقيدة فتح المنفذ المحلي (`listen EPERM`). لا نسجل المحاولتين نجاحًا لدورة المتصفح الكاملة؛ تتولى بوابات GitHub إكمالها على الشيفرة المرشحة قبل النشر.
