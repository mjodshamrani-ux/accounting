# تتبع تنفيذ منصة التسويات

6 أكتوبر 2026. التفويض يشمل تطوير المنصة متعددة التسويات، واختبار كل دفعة ومراجعتها ونشرها بعد اجتياز بواباتها. ترتيب القسم 11 من [الخطة المعتمدة](ENGINE-HACKATHON-PLAN.ar.md) هو المرجع؛ انتهاء حلقة الهاكاثون القصيرة لا ينهي خارطة التوسع.

## عقد المقاصة الأولى

جدول حركات واحد داخل مصدر CSV UTF-8 أو XLSX، ورقة واحدة مختارة، حتى حدود القارئ الحالية. يحدد المحاسب أعمدة رقم الحركة الفريد، مرجع المقاصة، التاريخ، المبلغ الموقع (أو المدين والدائن)، الحساب والعملة. التاريخ ISO، والمبلغ عشري صريح دون فواصل آلاف؛ هذه الدفعة لا تستنتج دلالة خلايا الملخص أو الرصيد أو تقلب الإشارة. رقم الحركة مختلف عن مرجع المقاصة ولا يحل محله. النطاق كيان ودفتر وحساب وعملة وفترة مثبتة بتصريح المستخدم؛ أعمدة الحساب والعملة تعاد مطابقتها لكل صف.

كل صف: رأس، فارغ، حركة صالحة، أو خطأ ظاهر بقيمه؛ لا حذف أو استبعاد يدوي يصنع تفردًا. أخطاء القراءة تمنع المقاصة كلها في هذه الدفعة مع حفظ الحركات الصحيحة للمراجعة. لا تسمى نتيجة المصدر بلا أخطاء شهادة اكتمال اقتصادي. المرجع الصريح يحمل حزمة كاملة، حتى 100 عضو؛ الصفر داخل جزء منها لا يُبحث عنه. صفرية إجمالي الحساب لا تخفي مجموعات غير مسوّاة. القرار البشري يحتاج أعضاء محددين وسببًا، ويظل بشريًا؛ لا يقبل جزءًا من حزمة مرجع صريح. الإلغاء يعيد المجموعة إلى المراجعة دون عودة آلية صامتة. تغيير الأصل أو الأعمدة أو النطاق يبطل سجل القرارات.

أول مثال معلوم: C001 = 1000 −600 −400؛ C002 = −500 +500؛ صفان بلا مرجع +75/−75 لا يعتمدان آليًا؛ C003 = 100 −90 تبقى للمراجعة. الحقيقة مستقلة مكتوبة في `audit/clearing/frozen/expected.json` قبل التنفيذ. البحث القديم يثبت صلاحية فكرة الحزمة، لكنه يستخدم جمع Number، ويرتب القرار البشري قبل المجموعة، ولا يعيد قراءة الأصل للتصدير؛ لا ينسخ إلى الإنتاج.
