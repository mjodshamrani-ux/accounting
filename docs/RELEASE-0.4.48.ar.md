# الإصدار 0.4.48

يوحّد هذا الإصدار العرض بين أنواع التسويات الاثني عشر. يبقى المشهد الرئيسي والمميزات والخطوات وتفاصيل الخصوصية في الصفحة عند اختيار مجال آخر أو بدء العمل. يمكن العودة إلى أعلى الصفحة أو تفاصيل الخصوصية دون تغيير التسوية أو فقدان ملفاتها ونتائجها. تتحدث الأوراق التوضيحية عن السجل الأول والثاني بدل حصر هوية الموقع في الموردين.

تستخدم خانات الرفع في المجالات الأخرى رسم الملف الأصلي نفسه الذي تستخدمه تسوية الموردين، مع ألوان الهوية والتفاعل عند المرور والتركيز والسحب. يبقى الرفع عبر عنصر الملف الأصلي وقارئ المجال، وتظل الصيغ المقبولة والإقفال أثناء المعالجة وتسميات الدور المالي كما هي. تراعي الحركة إعداد تقليل الحركة، وتبقى معرّفات الرسم فريدة رغم إبقاء المساحات غير النشطة مركّبة لحفظ العمل.

لا يضيف التوحيد مصادر اختيارية بدل الأدلة المطلوبة، ولا يغير قراءة الملفات أو الأرقام أو سياسة المطابقة أو إصدار المحرك. تعني الحركة التوضيحية قراءة السجلات عمومًا، ولا تمثل تقدمًا ماليًا فعليًا أو نجاح قراءة مصدر.

تتحقق اختبارات الدخول والواجهة المشتركة من ثبات أجزاء الصفحة نفسها عبر المجالات، والعودة بالتمرير إلى المشهد والخصوصية مع بقاء النوع المختار، وتطابق الرسم الأصلي في كل دور مصدر، واللغة والتركيز وتفرد مراجع SVG واحتفاظ العمل. تبقى الاختبارات المالية السابقة مستقلة ودون تخفيف توقعاتها. يشترط النشر نجاح CI وحارس المصادر وحزمة البناء، ثم فحص بايتات النسخة المنشورة والخط الأصلي وعرضها على الكمبيوتر والجوال.
