# إعداد الإصدار 0.4.46

يضيف المرشح عائلة مستندات العملاء `ar-scope-details-1` فوق الأساس المنشور 0.4.45. تقرأ رأس نطاق واحدًا وكتلة تفاصيل واحدة من CSV أو XLSX، وتربط كل تفصيل بأبيه الصريح. تورث هوية المنشأة والدفتر والعميل والحساب والعملة من خلايا الرأس الأصلية مع إحداثياتها؛ تبقى هوية المستند ونوعه وتاريخه ومبلغه الأصلي من التفصيل نفسه. لا يُستبدل المبلغ الأصلي بالرصيد المفتوح، ولا تُختلق تخصيصات قبض أو دعوى اكتمال مالي.

كل خطأ مصدر يمنع المطابقات الآلية. تحتفظ أوراق العمل بالصفوف المرفوضة والنص الأصلي وإحداثيات الرأس والتفصيل؛ لا تصبح الصفوف المرفوضة أعضاء ماليين. تعني المطابقة اتفاق هوية المستند وتاريخه ومبلغه ونطاقه وفق السياسة المحدودة، ولا تثبت توزيع المقبوضات. يبقى الرصيد المفتوح وصفًا غير متحقق. تتطلب حالات المراجعة المناسبة قرارًا صريحًا وسببًا، وتبطل القرارات عند تغيير الأصل أو القراءة أو النطاق.

تبقى عائلة AR السابقة وجلساتها متوافقة. للعائلة الجديدة أو المصدرين المختلطين إصدار جلسة صريح، مع الأصول والقراءة والنطاق والأحداث ثم إعادة الحساب. يلتقط العامل بيانات الطلب قبل إنشائه وأول انتظار، ويربط الرد بأصول الطلب الفعلية؛ يرفض الرد الأجنبي المتناسق والجلسة أو التصدير المستبدل. يبقى التصدير تسعة جداول بأعمدتها السابقة وإضافات أدلة العائلة الجديدة.

تستخدم الأقسام واجهة العمل المشتركة مع أسطح وحدود وتدرج عناوين مطابق لأسلوب الموردين، وشبكة نتائج متوازنة على الشاشات المختلفة. تعرض حالات AR شارة الحالة والمبلغ وتفاصيل العضوية منفصلة، مع أدلة المصدر القابلة للفتح. لا تغير تحسينات التنسيق السياسة المالية أو مساحة الموردين.

السعة: 8 MiB لكل أصل، و20000 تفصيل غير فارغ لكل مصدر، و32 MiB للجلسة و1000 حدث، و96 MiB للتصدير. يرفض التصدير الجديد أو المختلط بـ`AR_EXPORT_EVIDENCE_LIMIT` قبل بناء الجداول إذا تجاوز JSON التشخيصي لخلية Summary مقدار 32767 وحدة UTF-16، أو تجاوز تكرار مراجع أخطاء المصدر بين الحالات 8388608 وحدة UTF-16. لا تقص الأدلة. لذلك قد تنجح قراءة مصدر كثيف الأخطاء وحفظ جلسته مع تعذر تصديره ضمن هذا التخطيط؛ لا يعني حد القراءة دعم تصدير جميع توزيعات الأخطاء.

العقد والأوراكل والحقائق وعينات CSV/XLSX والمدقق المستقل محفوظة في `audit/ar-scope-details`. كل العينات اصطناعية؛ لا تحقق ميداني أو قياس لجهد المحاسب أو اختبار جهاز هاتف فعلي. تبقى بقية عائلات المصادر وAI وOCR العربي والأداء الموسع والخصوصية التاريخية مفتوحة. تحفظ أدلة التنفيذ الخاصة والمراجعة النهائية وSHA والشجرة وCI والفحص الحي خارج مصدر النشر. هذه الوثيقة لا تثبت النشر بمفردها؛ يلزم نجاح الفحوص والمراجعة المستقلة وCI دون تجاوز، ثم التحقق من النسخة الحية.
