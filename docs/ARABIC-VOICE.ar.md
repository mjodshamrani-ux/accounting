# أسلوب الكتابة في تراصف

تراصف تخاطب محاسبًا يريد فهم ملفاته وإنجاز عمله. نكتب بلغة عربية قريبة وواضحة، دون تكلف أو عامية يصعب فهمها خارج بيئة محددة. الدقة في وصف النتيجة أهم من جاذبية العبارة.

## الصوت

- نبدأ بما يحتاجه المحاسب: ما الذي حدث، وما معناه، وما الخطوة التالية إن كانت مطلوبة.
- نخاطبه مباشرة: «اختر الورقة التي تحتوي الحركات» بدل «يرجى القيام بتحديد ورقة العمل المراد استخدامها».
- نستخدم كلمة مألوفة عندما تؤدي المعنى نفسه: «على جهازك» بدل «محليًا»، و«قراءة الملف» بدل «استخراج البيانات بنيويًا».
- نحافظ على المصطلح المحاسبي حين يكون أدق: الرصيد الافتتاحي، المبلغ المستحق، المدين والدائن، ومقارنة الحركات.
- لا نكرر الفكرة بصيغ متتابعة، ولا نضيف أوصافًا مثل «الأذكى» أو «المثالي» أو «بدقة مطلقة».

## العناوين والأزرار

العنوان فكرة واحدة متصلة، بلا نقطة ختامية أو فواصل أو جمل دعائية متقطعة. هذا اختيار تحريري لتراصف، وليس قاعدة ندّعي أن جميع المواقع تتبعها. لا نحذف علامات الترقيم من الفقرات عندما تساعد على الفهم، ولا من الأرقام والمراجع والصيغ المحاسبية.

نسمّي الزر بحسب فعله: «اختيار ملف»، «تفاصيل الحالة»، «حفظ الجلسة للمتابعة لاحقًا». عند الحذف نوضح أثره: «مسح الجلسة والبدء من جديد». علامات الحذف مناسبة لحالة مستمرة مثل «جارٍ تجهيز أداة المقارنة…» وليست زينة للعناوين.

## أمثلة معتمدة

| قبل                    | بعد                                                | السبب                              |
| ---------------------- | -------------------------------------------------- | ---------------------------------- |
| نافذة المطابقة بالأيام | فرق الأيام المسموح للمطابقة                        | يوضح ما يتحكم فيه الحقل            |
| تاريخ القطع            | تاريخ المقارنة                                     | أقرب لفهم المستخدم في هذه الواجهة  |
| فحص                    | تفاصيل الحالة                                      | يوضح ما سيفتحه الزر                |
| جاهزة للخطوة التالية   | قرأنا الملف. راجع بياناته في الخطوة التالية.       | يفرق بين نجاح القراءة وصحة المحتوى |
| اكتملت قراءة الحركات   | لا توجد أخطاء قراءة متبقية والصفوف المستبعدة موثقة | لا يوحي بأن كل صف دخل في المقارنة  |

الأمثلة توضح المقصود التحريري؛ لا تمثل عقودًا برمجية للبحث والاستبدال الآلي.

## المعجم

| المعنى                    | الصياغة في الواجهة                |
| ------------------------- | --------------------------------- |
| Supplier statement        | كشف المورد                        |
| Accounts payable report   | تقرير الحسابات الدائنة            |
| Transaction comparison    | مقارنة الحركات                    |
| Balance reconciliation    | تسوية الأرصدة                     |
| Cut-off                   | تاريخ المقارنة                    |
| Date matching window      | فرق الأيام المسموح للمطابقة       |
| Confirmed automatic match | مطابقة آلية                       |
| Reviewer-confirmed match  | مطابقة يدوية                      |
| Candidate / needs review  | اقتراح / يحتاج مراجعة بحسب الحالة |
| Unmatched                 | دون مقابل في الملف الآخر          |
| Workpaper                 | ورقة العمل                        |
| Experimental OCR          | قراءة الصور التجريبية             |

«دون مقابل في الملف الآخر» لا يعني غياب الحركة من النظام المحاسبي. «مطابقة» لا تعني صحة القيد أو سداد الفاتورة. «فرق متبقٍ يساوي صفرًا» لا يثبت وحده اكتمال التسوية أو صحة تفسير الفروق.

## الأخطاء والحالات غير المؤكدة

توضح الرسالة المشكلة والإجراء المتاح دون لوم المستخدم أو الادعاء بمعرفة سبب لم نتحقق منه. نفرّق بين ملف رفضت قراءته، وصف تعذرت قراءته، وحركة قرئت ولم تجد مقابلًا. لا نسمي مسودة الصور بيانات متحققة ولا نصف اقتراح المساعد بأنه مطابقة مؤكدة.

تبقى حدود الحجم والصفحات والتنسيقات والمراجعة الإلزامية صريحة. لا نخفيها لتحسين النبرة. عند استمرار التحميل نذكر العمل الجاري؛ وعند فشل العملية لا نقول إنها اكتملت أو إن البيانات حُفظت.

## الخصوصية

نشرح السلوك الفعلي: معالجة الملفات داخل المتصفح، وعدم إرسالها إلى خادم معالجة، وعدم حفظ المعاملات تلقائيًا بين الجلسات. نوضح أن حفظ جلسة أو تنزيل Excel ينشئ ملفًا على الجهاز باختيار المستخدم. نحتفظ بالتفاصيل المتعلقة بتحميل أدوات الموقع وسجلات المضيف وحدود حماية الجهاز والإضافات. لا نستخدم «لا تحفظ أبدًا» أو «خصوصية مضمونة بالكامل».

## الأرقام والنصوص الديناميكية

- يبقى الرقم ووحدته ومصدره كما حسبها المحرك. تحسين الصياغة لا يغير المعادلة أو علامة المبلغ أو المرجع أو التاريخ.
- نراجع الجملة بعد إدخال قيم حقيقية فيها، بما فيها الصفر والواحد والجمع والأسماء الطويلة والمراجع الإنجليزية.
- لا نخلط عدد مجموعات المطابقة بعدد الحركات داخلها. نوفر وصفًا دقيقًا للوحدة المعروضة.
- عند ذكر الجانب نعرض اسم المصدر، لا فهرسًا داخليًا مثل 0 أو 1.
- عند التحضير للترجمة، تُترجم الجملة الكاملة حول متغيراتها. تبقى مفاتيح الحالات والبروتوكول وأسماء أوراق Excel التي يعتمد عليها الاستيراد مستقرة.

## المراجعة قبل النشر

اقرأ النص ضمن الشاشة بحجم الجوال والحاسوب، ثم اسأل: هل يعرف المحاسب ما حدث وما المطلوب؟ هل يمكن أن يفهم العبارة على أنها اعتماد لم يحصل؟ هل بقيت الأرقام والقيود ومصدر الدليل واضحة؟

تُحدّث توقعات النص في الاختبارات عند تغير الصياغة، مع الاحتفاظ بتأكيدات الأرقام والحالات ومنع الاعتماد غير المبرر. لا نغير عبارات التعرف على الملفات أو تعبيراتها المنتظمة لتحسين اللغة المعروضة.
