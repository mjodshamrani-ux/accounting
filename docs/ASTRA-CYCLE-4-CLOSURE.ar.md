# إغلاق مراجعة أسترا للدورة الرابعة

الإصدار المرشح 0.4.15، والمحرك 0.3.22-experimental. يكمل هذا القرار عقد F02-R1 ولا يغير ملفاته المجمدة أو فشل الإصدار السابق. تقرير سول في audit/sol-cycle4 يظل سجلًا تاريخيًا؛ نتائج المرشح تحفظ في audit/astra-cycle4.

## قرار عضوية الصف المستبعد

استبعاد صف حركة يخرجه من الحساب، لكنه لا يمحو هويته من اختبار المنافسة. يصنف التطبيع الصف من المصدر إلى غير حركة مثبتة، أو حركة مستبعدة يدويًا، أو حركة خارج الفترة. لا تحدد عبارة سبب الاستبعاد هذا التصنيف.

يحفظ الصف المستبعد يدويًا غلاف المراجع الآمن قبل تحليل المبلغ والتاريخ. تفحص شبكة عضوية واحدة الصفوف المقروءة والخاطئة والمستبعدة، وتشمل المراجع الأصلية والثانوية والقيم الحرفية التي قد تحمل هوية منزاحة. تستخدم التسوية المحافظة للمراجع لرفض التصادم فقط، ولا تستخدم لإثبات تطابق رمزين مختلفين. ينتقل أثر المنافسة عبر الهويات المترابطة قبل استهلاك الصفوف أو القرارات اليدوية أو الرفض أو تصفية التواريخ.

إذا تعذرت قراءة هوية حركة مستبعدة يدويًا، يبقى الملف والنتيجة قابلين للمراجعة، ويتوقف الاعتماد الآلي. إذا ثبت أن الأثر محصور في مراجع محددة، تبقى المطابقات المستقلة السليمة متاحة. يشمل ذلك الصف الفارغ المستبعد الذي يحمل مشكلة إخفاء أو قراءة؛ الفراغ الظاهر لا يثبت غياب حركة.

العناوين والأرصدة والإجماليات والتذييلات والصفوف الفارغة الآمنة تستثنى من المنافسة بقواعدها البنيوية الحالية. يسبق هذا الفحص الاستبعاد اليدوي، مع حفظ سبب المحاسب إذا أدخله. يسمح عنوان صفحة PDF المستبعد يدويًا بتغير عداد صفحة فقط عندما يساوي رقم الصفحة الأصلي، وتطابق بقية النصوص والأعمدة المقدمة الأصلية، ويتبعه رأس الجدول المطابق في الصفحة نفسها. لا يمنح عنوان مختلف أو مبلغ مع هوية هذا الاستثناء.

تبقى صفوف ما قبل بداية الفترة أو بعد القطع دليل منافسة سالبًا عند تداخل الهوية، ولا تتحول إلى حركات في الفترة. الصفوف القديمة التي لا تحمل تصنيفًا تستبقي كل قيمها الأصلية كدليل سالب، حتى إذا رافقها غلاف ناقص. جلسة أو ورقة عمل أو اقتراح AI لا يمنح شهادة للتجاوز؛ تعاد القراءة من الأصل عند الاستعادة والتصدير.

يمنع وجود حركة مستبعدة يدويًا إعلان اكتمال تسوية الأرصدة، حتى لو تساوت المجاميع بعد إسقاط حركتين متعاكستين. قرار المحاسب الصريح يبقى Manual Review، ولا يتحول إلى اعتماد آلي ولا يعالج نقص التغطية.

## العناوين والعملة والذكاء الاصطناعي

تعالج وسوم عملة عناوين XLSX وفق نفس توحيد محارف العناوين، بما فيها المحارف كاملة العرض، قبل فحص التعارض أو وراثة عملة الأب. تبقى النصوص الأصلية في المصدر ودليل الأصول كما هي. يمنع اختلاف عملة عنوان المبلغ عن النطاق في الرأس العادي والمركب.

يفحص verifyHypothesis شبكة العضوية نفسها. لا يقبل تفسيرًا حسابيًا لمجموعة متأثرة بمنافس مستبعد، ولا يغير الحالة أو الأرقام. النتيجة غير السليمة بنيويًا ترفض داخل حد التحقق بدل إخراج استثناء إلى الواجهة. يبقى تساوي المجموع في اقتراح مستقل مجرد معلومة للمراجعة.

## حدود الإصدار

رأس XLSX المركب المدعوم صفان أصليان وفق عقد F02. لم نوسع اعتماد المجموعة الأصلية 780+220، ولا سياسة CN-3، ولا نعتبر PO / Bank reference دورًا بنكيًا صريحًا. نجاح الاختبارات الاصطناعية ليس ضمانًا لكل كشف مورد أو دقة عامة 100%، وهذه الحالات عينات تطوير واختبارات رجوع وليست Holdout جديدًا.

تغيرت قرارات الاعتماد، ولذلك زاد إصدار المحرك. الجلسات القديمة لا تستعاد بصمت تحت قواعد مختلفة؛ تبقى الملفات الأصلية قابلة لإعادة الرفع. مدققات Excel المستقلة تبقي نسختها القديمة افتراضيًا، وتستقبل إصدار المرشح المتوقع صراحةً عند فحص الإصدار الجديد، دون تغيير أي حقيقة مالية مجمدة.

ملاحظة تحقق مهمة: سجل اختبار OCR العربي للصور 0 من 3 مبالغ متطابقة نصيًا في العينة. هذه فجوة قراءة معلنة وليست نجاحًا ماليًا؛ تظل مقترحات الصورة للمراجعة، ولا تكتسب صلاحية المطابقة أو تعديل مبلغ. لا تشمل نتيجة هذه الدورة إثبات قراءة الصور العربية المحاسبية تلقائيًا.
