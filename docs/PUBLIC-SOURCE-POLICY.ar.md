# سياسة المصدر العام

الشفرة والأصول العامة والعينات الاصطناعية القابلة للتحقق وحدها تصلح لمصدر النشر. يحتفظ `public-safe-manifest.json` بالمسارات المسموحة وحجمها وبصمتها وتصنيفها؛ يتطلب الملف الثنائي أيضًا وصف مصدر آمن محددًا. القائمة لا تتضمن عناوين الأدلة الخاصة أو جرد الأجسام المحجوزة أو بصماتها.

قد تحتوي حزم JavaScript المبنية من الشفرة ومكتبات القفل المثبتة على رموز تحكم حرفية تخص قارئات ZIP/XML أو بيانات المحللات المجمعة. تبقى هذه الحزم ذات بصمات ومصدر بناء محدد، وتصنف صراحةً مع فحص UTF-8 الصحيح وLatin-1 وUTF-16. لا يسمح ذلك بتجاوز فحص النصوص أو اعتبار ملف مجهول آمنًا لمجرد امتداده. ملفات الخطوط غير المحسوم إذن توزيعها تبقى خارج قائمة النشر والبناء.

المراجعات المحلية الخام والأرشيفات والصور والملفات الميدانية وسجلات التشغيل لا تدخل قائمة النشر بمجرد وجودها في المستودع القديم. تحذف نسخها من رأس المرشح العام وتبقى أصولها المحلية محفوظة. تستبقي النسخة العامة عقود الاختبار وحقائق الأوراكل؛ تنظيف بيانات الجهاز ليس إذنًا لتغيير مبلغ أو عضوية أو نتيجة متوقعة أو اختلاق تجربة جديدة.

يفحص الحارس النصوص ومحتويات ZIP وXLSX وGZIP المدعومة، ويرفض الأرشيفات المتداخلة والصيغ غير المدعومة. يفك بيانات PNG الوصفية المدعومة، ويقبل في PDF النص غير المضغوط أو مرشح Flate واحدًا أو الزوج المحدد ASCII85 ثم Flate المستخدم في عينات ReportLab الأصلية. يفك كلا المرشحين بالترتيب ويرفض التكرار والسلاسل الأخرى. ترفض الملفات غير المدرجة وتغير البصمات والمحتوى غير المسموح. لا تثبت هذه الفحوص وحدها سلامة أرقام مالية أو بكسلات أو خطوط أو أصول المورد؛ يلزم فحص مصدرها خارجيًا وربط القائمة الكاملة بالمراجعة المستقلة. وصف المصدر داخل القائمة تصريح من المراجعة، وليس برهانًا ينتجه الحارس.

مصدر الفحص النهائي نسخة Git نظيفة؛ المخرجات المحلية المؤقتة ليست جزءًا من المصدر العام وحزمة الموقع تفحص مستقلة قبل رفعها. تشمل المراجعة البشرية الأصول العامة والعينات الصناعية وبنيتها ومصدر حقائقها قبل تثبيت بصماتها.

كل فحوص المحاسبة والواجهة تظل شرطًا. يسمح CI برفع حزمة Pages المراجعة فقط ويحتفظ بالأدلة الخام خارج النشر. نتائج المصدر الميداني القديم لا تنقل إلى عينات اصطناعية كأنها التحقق نفسه. يوثق اختلاف التغطية وحدود المصدر في المراجعة المحلية.
