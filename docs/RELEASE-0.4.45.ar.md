# إعداد الإصدار 0.4.45

يضيف المرشح اختيارًا صريحًا لعائلة معاملات البوابات `payment-gateway-signed-kind-1` فوق main المنشور 0.4.44. يقبل البيع غير السالب والاسترداد غير الموجب بنوع مقدم، ويرفض الصفر السالب والإشارة المخالفة قبل التحويل العددي. يحفظ النص والإشارة والقيمة الموقعة والمقدار الحسابي منفصلة في المصدر والتصدير. لا تتغير عائلة البوابات السابقة أو إصدار المحرك والجلسة.

يبقى المصدر أربعة أصول محلية مستقلة: المعاملات، ودليل الرسوم، والتسوية، والإيداع البنكي. لا تُشتق الرسوم من الفرق، ولا تعوض مطابقة الصافي وحدها اختلاف المكونات الأربعة. تشمل المراجعة الصفوف الصفرية والخاطئة والمتكررة، ويلزم تأكيد النطاق والقراءة واكتمال العضوية ثم قرار يدوي. تعديل الأصل أو العائلة يبطل القرارات السابقة.

تُقرأ CSV بدقة وحدات العملة SAR/JPY/KWD؛ وXLSX المالي العددي الجديد مقيد بـSAR وتنسيق عشري صريح، مع فحص XML الأصلي قبل أي تحويل. تبقى حراسة البنك العامة والقيود الأصلية دون توسيع. عينتا XLSX التحضيريتان بملف worksheet غير نمطي وخط خارج حدود القارئ تُرفضان؛ اختبارات native المدعومة منفصلة، ولا تُنسب جميع حالات الأوراكل الـ58 إلى نجاح منتج شامل.

تلتقط عمليات العامل الأصول والبيانات قبل إنشاء العامل؛ وتعيد التحقق من بايتات الطلب والجلسة والصادرات، وترفض الرد المتناسق المرتبط بمصدر أجنبي. الإلغاء والرد المتأخر وإعادة المحاولة ضمن الفحوص. تستخدم الواجهة مساحة العمل المشتركة والتفاصيل والقرارات والحفظ والتصدير الحالية، بالعربية والإنجليزية، مع اختيار واضح للعائلة والمبلغ الموقّع.

البيانات الاختبارية اصطناعية معلنة؛ لا أصول ميدانية أو قياس أداء جهاز ضعيف أو خفض مثبت لجهد المحاسب. يحفظ هذا المصدر عقودًا وأوراكل ومدقق Excel مستقلًا وبوابات طفرات وواجهة؛ تحفظ نتائج التنفيذ والمراجعة وSHA/الشجرة وبوابات CI والفحص الحي خارج مصدر النشر. لا تمثل هذه الوثيقة بمفردها دليل نشر أو قبول مستقل. تبقى شروط النشر: المراجعة المستقلة للشجرة النهائية، والفحوص المحلية وCI كاملة دون تجاوز، وتطابق قائمة المصدر والبناء، ثم فحص الموقع الحي وفق التفويض.
