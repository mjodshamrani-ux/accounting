Re-read [domain IDs](../../../../lib/i18n/reconciliation-directory.ts), [workspace identity](../../../../docs/WORKSPACE-IDENTITY.ar.md) and the affected component's current labels, types, input handlers and tests. The table records source count and `primaryIndices` at the reviewed baseline. These are **presentation indices**, not permission to reorder engine arrays. Additional sources remain required by their actual contracts. Supplier is one domain among twelve.

Plans contain implemented history **and future work**. Verify current source families, formats, gates and scope in code/state before exposing a capability. For example, generic PDF parsing does not authorize every domain to accept arbitrary PDF. A source counter must reflect the chosen path, not a universal “two files” promise.

For a shared change, verify all twelve domains retain one selector, appropriate main landmark/heading, correct required roles, original upload controls, preserved state across navigation/language, and processing locks. For a local change, test its domain plus affected shared behavior. Do not run only supplier tests and infer parity.
